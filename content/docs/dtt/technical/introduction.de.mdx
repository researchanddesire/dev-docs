## Fehlerbehebung

Wenn Ihr Trainer auf ein Problem stößt, zeigt er einen Fehlercode auf dem Bildschirm an:

<Card title="E-DTT-1: Kein Internet" icon="wifi-exclamation" href="../errors/e-dtt-1">
  Ihr Gerät ist mit WLAN verbunden, kann den Server jedoch nicht erreichen. Erfahren Sie, wie Sie die Firewall- und Router-Einstellungen anpassen.
</Card>

Eine vollständige Liste der Fehlercodes und Meldungen finden Sie im Handbuch <a href="./error-codes">Error Codes</a>.

## Benötigen Sie zusätzliche Hilfe?

Wenn Sie die Schritte zur Fehlerbehebung befolgt haben und das Problem weiterhin besteht, wenden Sie sich an unser Support-Team mit:

- Der spezifische Fehlercode, der auf Ihrem Gerät angezeigt wird
- Ihre Trainer-ID (wird beim Start angezeigt)
- Eine kurze Beschreibung der Schritte, die Sie bereits versucht haben

<Tip>
Bevor Sie sich an uns wenden, versuchen Sie, sowohl Ihren Trainer als auch Ihren Router neu zu starten. Viele Verbindungsprobleme lösen sich nach einem Neustart.
</Tip>
