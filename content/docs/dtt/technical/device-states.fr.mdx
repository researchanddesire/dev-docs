---

Votre Deepthroat Trainer passe par différents états pendant son fonctionnement, chacun avec son propre écran. Comprendre ces états vous aide à naviguer dans l’appareil et à résoudre les problèmes éventuels.

## Séquence de démarrage

Lorsque vous allumez votre Deepthroat Trainer, il passe par les états suivants :

### Écran de bienvenue
- Affiche votre **Trainer ID** (code alphanumérique à 5 caractères)
- Affiche l’état de la connexion Wi-Fi
- **Timeout** : 15 secondes avant le passage automatique à l’écran suivant

<Info>
Notez votre Trainer ID : vous en aurez besoin pour associer l’appareil à votre compte du tableau de bord.
</Info>

### Vérifications préalables
Après l’écran de bienvenue, l’appareil effectue des vérifications système :
- Vérifie la connexion Wi-Fi
- Vérifie si l’appareil est associé
- Recherche les mises à jour disponibles

L’écran affiche "Getting ready..." pendant que ces vérifications se terminent.

## Configuration Wi-Fi

### Écran de configuration Wi-Fi
Affiché lorsque vous entrez dans le mode de configuration Wi-Fi :
- Affiche un code QR pour faciliter la connexion
- Affiche "Connect to 'Trainer Setup'"
- **Accès** : appuyez longuement pendant l’affichage de l’écran de bienvenue

<Tip>
Le portail de configuration Wi-Fi a un délai d’expiration de 400 secondes. À son expiration, l’appareil redémarre.
</Tip>

## État d’association

Si votre appareil n’est pas associé à un compte du tableau de bord :
- Affiche un code QR qui renvoie vers les paramètres du tableau de bord
- Affiche "Pair me for more settings and fun!"
- Appuyez sur le bouton pour ignorer cette étape et continuer hors ligne

## État de mise à jour

Lorsqu’une mise à jour du firmware est disponible :
- Affiche "Updating" avec un indicateur de progression
- Affiche "Thanks for waiting! You're almost ready to play."
- L’appareil redémarre automatiquement après la mise à jour

<Warning>
N’éteignez pas l’appareil pendant une mise à jour. Attendez qu’elle soit terminée et que l’appareil redémarre automatiquement.
</Warning>

## États du flux de jeu

### Écrans de pré-session

| Écran | Description |
|--------|-------------|
| **Vérifications préalables** | "Getting ready..." — vérifie la connectivité et les paramètres |
| **Récupération des paramètres** | "I'm getting your settings from the dashboard." |
| **Chargement des paramètres** | "You're offline, your grades may not be saved." (mode hors ligne) |
| **Échec de la vérification d’intégrité** | Erreur E-DTT-1 — consultez le <a href="https://docs.researchanddesire.com/dtt/troubleshooting">guide de dépannage</a> |

### Écrans d’étalonnage

| Écran | Description |
|--------|-------------|
| **Étalonnage min.** | Capture la position minimale (la plus proche) — appuyez sur le bouton lorsque vous êtes prêt |
| **Étalonnage max.** | Capture la position maximale (au repos) — appuyez sur le bouton lorsque vous êtes prêt |

<Note>
L’étalonnage capture 100 échantillons à chaque position pour garantir la précision. Maintenez l’appareil immobile lorsque vous appuyez sur le bouton.
</Note>

### Détails de la session

Avant le début de l’entraînement, des écrans d’information s’affichent :

| Écran | Contenu | Timeout |
|--------|---------|---------|
| **Détails de la session** | Nom de la session, nombre total de segments | 10 secondes |
| **Détails du jouet** | Nom et paramètres du jouet attribué | 10 secondes |
| **Détails du segment** | Nom et paramètres du segment actuel | 10 secondes |

<Tip>
En Hands-Free Mode (Ultra), ces écrans avancent automatiquement. Sinon, appuyez sur le bouton pour continuer.
</Tip>

### Écrans d’entraînement

| Écran | Description |
|--------|-------------|
| **Compte à rebours** | "Starting in 3... 2... 1... Good Luck!" |
| **Entraînement actif** | Affichage en temps réel de la position, de la cible et de la progression |
| **Note** | Votre score et vos commentaires sur vos performances (timeout : 30 secondes) |

### Écrans de réussite ou d’échec (si activés)

| Écran | Description | Timeout |
|--------|-------------|---------|
| **Échec** | Affiche "Failed" avec le nombre de tentatives (par exemple, "Attempt 1/3") | Appuyez pour réessayer |
| **Three Strikes** | "YOU FAIL - 3 failed attempts" — la session redémarre | 5 secondes |

### Session terminée

| Écran | Description |
|--------|-------------|
| **Page finale** | "Well done! You finished the session." (timeout : 10 secondes) |

La LED devient magenta sur la page finale pour célébrer la fin de la session.

## États d’erreur

| Erreur | Contenu de l’écran |
|-------|----------------|
| **E-DTT-1** | "No internet. Check firewall and router." |
| **Erreur de segment** | En-tête "ERROR" avec une option de réinitialisation |

Consultez le guide <a href="https://docs.researchanddesire.com/dtt/troubleshooting">Codes d’erreur</a> pour obtenir des instructions de dépannage détaillées.

## Vue d’ensemble du diagramme d’état

```
Power On → Welcome → Preflight → [Update if available]
                              → [Pairing if needed]
                              → Play Preflight → Fetch/Load Settings
                                              → Calibration (if needed)
                                              → Session Details
                                              → Countdown → Training
                                              → Grade → [Next Segment or Final]
```

## Actions des boutons selon l’état

| État | Appui court | Appui long |
|-------|-------------|------------|
| Bienvenue | Démarrer les vérifications préalables | Ouvrir la configuration Wi-Fi |
| Détails de la session | Écran suivant | Passer à l’entraînement |
| Détails du segment | Démarrer le segment | Passer à l’entraînement |
| Note | Segment suivant | — |
| Échec | Réessayer le segment | — |
| Page finale | Rejouer | — |
