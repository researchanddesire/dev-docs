## Dépannage

Lorsque votre Trainer rencontre un problème, il affiche un code d'erreur à l'écran :

<Card title="E-DTT-1 : Pas d'Internet" icon="wifi-exclamation" href="../errors/e-dtt-1">
  Votre appareil est connecté au Wi-Fi mais ne peut pas atteindre le serveur. Découvrez comment ajuster les paramètres du pare-feu et du routeur.
</Card>

Pour une liste complète des codes d'erreur et des messages, consultez le guide <a href="./error-codes">Codes d'erreur</a>.

## Besoin d'une aide supplémentaire ?

Si vous avez suivi les étapes de dépannage et que votre problème persiste, contactez notre équipe d’assistance en indiquant :

- Le code d'erreur spécifique affiché sur votre appareil
- Votre Trainer ID (affiché au démarrage)
- Une brève description des étapes que vous avez déjà essayées

<Tip>
Avant de nous contacter, essayez de redémarrer votre Trainer et votre routeur. De nombreux problèmes de connectivité sont résolus après un redémarrage.
</Tip>
