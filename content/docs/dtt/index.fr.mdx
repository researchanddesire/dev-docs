# Deepthroat Trainer

Utilisez les [spécifications de l'appareil](/dtt/specs/introduction) pour la
recharge et le port accessoire pris en charge. Utilisez la [référence
technique](/dtt/technical/introduction) pour l'étalonnage, les états de
l'appareil, les limites du capteur, le comportement hors ligne et les mises à
jour du micrologiciel.

Pour le montage, l'appairage, les jouets, les sessions ou les résultats, utilisez
le [Guide de l'utilisateur DTT](https://docs.researchanddesire.com/dtt/get-started).
