title: "Offline-Modus"
description: "Wie Ihre Chastity Lockbox funktioniert, wenn sie nicht mit WiFi oder dem Dashboard verbunden ist"
---

Ihre Chastity Lockbox ist dafür ausgelegt, sowohl online als auch offline zu funktionieren. In dieser Anleitung wird erklärt, was ohne WiFi funktioniert, welche Funktionen eine Verbindung erfordern und wie das Gerät den Wechsel zwischen Online- und Offline-Zuständen handhabt.

## Was offline funktioniert

Diese Funktionen funktionieren vollständig ohne Internetverbindung:

| Funktion | Offline-Verhalten |
|---------|-----------------|
| Zeitgesteuerte Sperren | Der Timer zählt lokal weiter herunter |
| Verriegelungs-/Entriegelungsmechanismus | Das physische Schloss verriegelt und entriegelt |
| Menünavigation | Alle Menüs sind zugänglich |
| Tastensteuerung | Vollständige Funktionalität |
| Schlafmodi | Automatische und manuelle Schlafmodi funktionieren |
| Notentriegelung | Kann lokal verwendet werden (falls aktiviert) |
| Zustandspersistenz | Der Sperrstatus bleibt nach Neustarts erhalten |

<Tip>
Wenn Sie an einen Ort ohne WiFi fahren, funktioniert Ihr Schloss weiterhin. Der Timer läuft auf dem Gerät selbst und nicht auf einem Server.
</Tip>

## Was WiFi erfordert

Für diese Funktionen ist eine aktive WiFi-Verbindung erforderlich:

| Funktion | Warum WiFi benötigt wird |
|---------|-------------------|
| Kopplung | Das Gerät muss beim Dashboard-Server registriert werden |
| Firmware-Updates | Downloads vom Update-Server |
| Dashboard-Synchronisierung | Empfängt Befehle des Schlüsselhalters |
| Zeitsynchronisierung | Erhält die genaue Uhrzeit vom NTP-Server |
| Aktivitätsprotokollierung | Sendet Ereignisse an das Dashboard |
| Öffentliche Abstimmung | Empfängt Abstimmungsaktualisierungen |
| Entriegelung durch den Schlüsselhalter | Befehle zur Fernentriegelung |

## Zeitanzeige im Offline-Modus

Wenn Ihr Gerät nicht mit WiFi verbunden ist und die Zeit nicht synchronisiert wurde, wird auf dem Sperrbildschirm Folgendes angezeigt:

> "Connect Wi-Fi to see time remaining"

<Warning>
Ohne Zeitsynchronisierung kann das Gerät die verbleibende Zeit nicht genau anzeigen. Der Sperrtimer selbst läuft jedoch weiterhin korrekt auf Grundlage der konfigurierten Dauer.
</Warning>

### Warum das passiert

Das Gerät muss die aktuelle Uhrzeit kennen, um „time remaining“ zu berechnen. Ohne NTP-Synchronisierung:
- Das Gerät kennt die Sperrdauer
- Das Gerät weiß nicht, wie spät es jetzt ist
- Daher kann es „time remaining“ nicht berechnen

Sobald WiFi verbunden und die Zeit synchronisiert ist, wird die Anzeige aktualisiert und zeigt die genaue verbleibende Zeit an.

## Modus „local play“

Wenn Sie eine Sperre direkt auf dem Gerät starten (nicht über das Dashboard), arbeitet es im Modus „local play“:

### Eigenschaften des Modus „local play“

- Die Sperrdauer wird lokal auf dem Gerät gespeichert
- Der Timer läuft unabhängig vom Server
- Eine Beteiligung des Schlüsselhalters ist nicht erforderlich
- Die Sperre endet, wenn der Timer abläuft

### Dashboard-Sperren

Wenn eine Sperre über das Dashboard gestartet wird:

- Die Einstellungen werden über WiFi mit dem Gerät synchronisiert
- Pausenpläne werden empfangen
- Die Notentriegelung kann aus der Ferne deaktiviert werden
- Der Schlüsselhalter kann die Sperre aus der Ferne ändern

<Info>
Lokale Sperren (auf dem Gerät gestartet) können nicht über das Dashboard geändert werden. Dashboard-Sperren können auch offline von Ihrem Schlüsselhalter geändert werden – die Änderungen werden synchronisiert, sobald Sie die Verbindung wiederherstellen.
</Info>

## Zustandspersistenz

Ihr Gerät behält seinen Zustand über Folgendes hinweg:

- Neustarts
- Aus-/Einschaltzyklen
- WiFi-Unterbrechungen
- Deep sleep

Die folgenden Daten bleiben erhalten:

| Daten | Speicher |
|------|---------|
| Sperrstatus (gesperrt/entsperrt) | Nichtflüchtiger Speicher |
| Endezeit der Sperre | Nichtflüchtiger Speicher |
| Sitzungseinstellungen | Nichtflüchtiger Speicher |
| WiFi-Anmeldedaten | Nichtflüchtiger Speicher |
| Kalibrierungsdaten | Nichtflüchtiger Speicher |

<Note>
Selbst wenn Ihr Gerät vollständig die Stromversorgung verliert, kehrt es beim Einschalten in den gesperrten Zustand zurück.
</Note>

## Verhalten bei der WiFi-Wiederverbindung

Wenn die WiFi-Verbindung während des Betriebs getrennt wird:

1. **Sofort**: Das Gerät funktioniert normal weiter
2. **Alle 30 Sekunden**: Automatischer Wiederverbindungsversuch
3. **Bei erneuter Verbindung**: Der Status wird mit dem Dashboard synchronisiert

### Manuelle WiFi-Einrichtung

Sie können WiFi jederzeit über folgende Menüs neu konfigurieren:
- Main Menu → Settings → WiFi Settings
- Lock Menu → WiFi Settings (while locked)

Dadurch wird das Konfigurationsportal geöffnet, ohne Ihren Sperrstatus zu beeinträchtigen.

## Offline-Szenarien

### Szenario 1: WiFi fällt während der Sperre aus

- Der Sperrtimer läuft normal weiter
- Die Anzeige "Connecting" wird in der Statusleiste angezeigt
- Automatische Wiederverbindungsversuche alle 30 Sekunden
- Das Schloss wird entsperrt, wenn der Timer abläuft (kein WiFi erforderlich)

### Szenario 2: Sperre ohne WiFi starten

- Navigieren Sie im Menü zu "Lock"
- Stellen Sie die Dauer mit dem Encoder ein
- Drücken Sie zur Bestätigung "Enter"
- Die Sperre wird lokal aktiviert
- Die Zeitanzeige zeigt "Connect Wi-Fi to see time remaining"
- Der Timer zählt weiterhin korrekt herunter

### Szenario 3: Reise an einen Ort ohne WiFi

- Das Gerät funktioniert normal
- Das Dashboard kann keine Befehle senden
- Die lokale Notentriegelung bleibt verfügbar (falls aktiviert)
- Bei der Rückkehr zu WiFi wird der Status automatisch synchronisiert

### Szenario 4: Deep sleep trennt WiFi

- WiFi wird in Deep sleep getrennt (Energiesparmodus)
- Der Sperrstatus bleibt unverändert
- Beim Aufwachen verbindet sich WiFi automatisch wieder
- Ausstehende Dashboard-Befehle werden empfangen

## Details zur Dashboard-Synchronisierung

Wenn Sie online sind, synchronisiert sich Ihr Gerät regelmäßig mit dem Dashboard:

### Ausgehend (Gerät → Dashboard)

- Änderungen des Sperrstatus
- Tastendrücke
- Sensorwerte
- Nutzung der Notentriegelung
- Pausentiming

### Eingehend (Dashboard → Gerät)

- Sperrbefehle
- Entsperrbefehle
- Aktualisierungen der Pausenpläne
- Änderungen der Sitzungseinstellungen
- Einstellungen für die Zeitanzeige

<Info>
Die Synchronisierung erfolgt über MQTT, um eine Reaktion in Echtzeit zu ermöglichen. Befehle treffen online normalerweise innerhalb weniger Sekunden ein.
</Info>

## Fehlerbehebung bei Offline-Problemen

<AccordionGroup>
<Accordion title="Die verbleibende Zeit wird nicht angezeigt">
Verbinden Sie sich mit WiFi, um die Zeit zu synchronisieren. Die Sperre läuft weiter – Sie können den Countdown erst sehen, wenn die Zeitsynchronisierung abgeschlossen ist.
</Accordion>

<Accordion title="Befehle des Schlüsselhalters können nicht empfangen werden">
Ihr Gerät muss online sein, um Dashboard-Befehle zu empfangen. Überprüfen Sie den WiFi-Verbindungsstatus in der Statusleiste.
</Accordion>

<Accordion title="Die Sperre ist beendet, aber das Dashboard zeigt weiterhin „gesperrt“ an">
Das Dashboard wird aktualisiert, sobald Ihr Gerät wieder eine Verbindung herstellt. Verbinden Sie sich mit WiFi, damit der Status synchronisiert wird.
</Accordion>

<Accordion title="WiFi wird nicht automatisch wieder verbunden">
Gehen Sie zu Settings → WiFi Settings, um die Verbindung manuell wiederherzustellen. Ihr Sperrstatus bleibt davon unberührt.
</Accordion>
</AccordionGroup>
