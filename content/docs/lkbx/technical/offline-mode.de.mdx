description: "Wie Ihr Keuschheitsschloss funktioniert, wenn keine Verbindung zu WLAN oder dem Dashboard besteht"
---

Ihr Keuschheitsschloss ist so konzipiert, dass es sowohl online als auch offline funktioniert. In dieser Anleitung wird erklärt, was ohne WLAN funktioniert, was eine Konnektivität erfordert und wie das Gerät mit Übergängen zwischen Online- und Offline-Zuständen umgeht.

## Was funktioniert offline?

Diese Funktionen funktionieren vollständig ohne Internetverbindung:

| Besonderheit | Offline-Verhalten |
|---------|-----------------|
| Zeitgesteuerte Sperren | Der Timer zählt lokal weiter herunter |
| Sperr-/Entriegelungsmechanismus | Die physische Sperre wird aktiviert und freigegeben |
| Menünavigation | Alle Menüs zugänglich |
| Tastensteuerung | Volle Funktionalität |
| Schlafmodi | Automatische und manuelle Schlaffunktion |
| Notentriegelung | Kann lokal verwendet werden (falls aktiviert) |
| Staatliche Persistenz | Der Sperrzustand übersteht Neustarts |

<Tip>
Wenn Sie ohne WLAN unterwegs sind, funktioniert Ihr Schloss weiterhin. Der Timer läuft auf dem Gerät selbst, nicht auf einem Server.
</Tip>

## Was erfordert WLAN?

Für diese Funktionen ist eine aktive WLAN-Verbindung erforderlich:

| Besonderheit | Warum WLAN benötigt wird |
|---------|-------------------|
| Paarung | Das Gerät muss beim Dashboard-Server registriert sein |
| Firmware-Updates | Downloads vom Update-Server |
| Dashboard-Synchronisierung | Empfängt Schlüsselhalterbefehle |
| Zeitsynchronisation | Erhält die genaue Uhrzeit vom NTP-Server |
| Aktivitätsprotokollierung | Sendet Ereignisse an das Dashboard |
| Öffentliche Abstimmung | Erhält Abstimmungsaktualisierungen |
| Schlüsselhalter-Entriegelung | Fernentriegelungsbefehle |

## Zeitanzeige im Offline-Modus

Wenn Ihr Gerät nicht mit WLAN verbunden ist und die Zeit nicht synchronisiert hat, wird auf dem Sperrbildschirm Folgendes angezeigt:

> „WLAN verbinden, um die verbleibende Zeit anzuzeigen“

<Warning>
Ohne Zeitsynchronisierung kann das Gerät die verbleibende Zeit nicht genau anzeigen. Der Sperr-Timer selbst läuft jedoch basierend auf der konfigurierten Dauer immer noch korrekt.
</Warning>

### Warum das passiert

Das Gerät muss die aktuelle Zeit kennen, um die „verbleibende Zeit“ berechnen zu können. Ohne NTP-Synchronisierung:
- Das Gerät kennt die Sperrdauer
- Das Gerät weiß nicht, wie spät es jetzt ist
- Daher kann die verbleibende Zeit nicht berechnet werden

Sobald die WLAN-Verbindung hergestellt und die Zeit synchronisiert ist, wird die Anzeige aktualisiert, um die genaue verbleibende Zeit anzuzeigen.

## Lokaler Wiedergabemodus

Wenn Sie eine Sperre direkt auf dem Gerät starten (nicht über das Dashboard), arbeitet es im „Local Play“-Modus:

### Lokale Spieleigenschaften

- Die Sperrdauer wird lokal auf dem Gerät gespeichert
- Der Timer läuft unabhängig vom Server
- Keine Beteiligung des Schlüsselinhabers erforderlich
- Die Sperre endet, wenn der Timer abläuft

### Armaturenbrettschlösser

Wenn eine Sperre über das Dashboard gestartet wird:

- Die Einstellungen werden über WLAN mit dem Gerät synchronisiert
- Pausenpläne liegen vor
- Die Notentriegelung kann aus der Ferne deaktiviert werden
- Der Schlüsselinhaber kann das Schloss aus der Ferne ändern

<Info>
Lokale Sperren (auf dem Gerät gestartet) können nicht über das Dashboard geändert werden. Dashboard-Sperren können von Ihrem Schlüsselinhaber auch dann geändert werden, wenn Sie offline sind – die Änderungen werden synchronisiert, wenn Sie die Verbindung wiederherstellen.
</Info>

## Staatliche Persistenz

Ihr Gerät behält seinen Zustand über Folgendes hinweg:

- Neustarts
- Leistungszyklen
- WLAN-Unterbrechungen
- Tiefer Schlaf

Folgende Daten bleiben bestehen:

| Daten | Lagerung |
|------|---------|
| Sperrzustand (gesperrt/entsperrt) | Nichtflüchtiger Speicher |
| Endzeit sperren | Nichtflüchtiger Speicher |
| Sitzungseinstellungen | Nichtflüchtiger Speicher |
| WLAN-Zugangsdaten | Nichtflüchtiger Speicher |
| Kalibrierungsdaten | Nichtflüchtiger Speicher |

<Note>
Selbst wenn Ihr Gerät vollständig ausfällt, kehrt es beim Einschalten in den gesperrten Zustand zurück.
</Note>

## WLAN-Wiederverbindungsverhalten

Wenn WLAN während des Betriebs getrennt wird:

1. **Sofort**: Das Gerät funktioniert normal weiter
2. **Alle 30 Sekunden**: Automatischer Wiederverbindungsversuch
3. **Bei erneuter Verbindung**: Synchronisiert den Status mit dem Dashboard

### Manuelle WLAN-Einrichtung

Sie können WLAN jederzeit neu konfigurieren über:
- Hauptmenü → Einstellungen → WLAN-Einstellungen
- Sperrmenü → WLAN-Einstellungen (im gesperrten Zustand)

Dadurch wird das Konfigurationsportal geöffnet, ohne dass sich dies auf Ihren Sperrstatus auswirkt.

## Offline-Szenarien

### Szenario 1: WLAN fällt während der Sperre aus

- Der Sperrtimer läuft normal weiter
- Die Anzeige „Verbinden“ wird in der Statusleiste angezeigt
- Automatische Wiederverbindungsversuche alle 30 Sekunden
- Das Schloss wird entsperrt, wenn der Timer abläuft (kein WLAN erforderlich)

### Szenario 2: Startsperre ohne WLAN

- Navigieren Sie zum Menü „Sperren“.
- Dauer mit Encoder einstellen
- Drücken Sie zur Bestätigung die Eingabetaste
- Schloss rastet lokal ein
- Die Zeitanzeige zeigt „WLAN verbinden, um die verbleibende Zeit anzuzeigen“
- Der Timer zählt immer noch korrekt herunter

### Szenario 3: Ohne WLAN zum Standort reisen

- Gerät funktioniert normal
- Dashboard kann keine Befehle senden
- Lokale Notentriegelung weiterhin verfügbar (falls aktiviert)
- Bei der Rückkehr zum WLAN wird der Status automatisch synchronisiert

### Szenario 4: Tiefschlaf unterbricht die WLAN-Verbindung

- WLAN wird im Tiefschlaf getrennt (Energiesparen)
- Sperrzustand unverändert
- Beim Aufwachen stellt das WLAN automatisch wieder eine Verbindung her
- Ausstehende Dashboard-Befehle empfangen

## Details zur Dashboard-Synchronisierung

Wenn Sie online sind, synchronisiert sich Ihr Gerät regelmäßig mit dem Dashboard:

### Ausgehend (Gerät → Dashboard)

- Änderungen des Sperrstatus
- Knopfdruck
- Sensorwerte
- Verwendung zur Notentriegelung
- Pausenzeitpunkt

### Eingehend (Dashboard → Gerät)

- Befehle sperren
- Befehle entsperren
- Aktualisierungen des Pausenplans
- Änderungen der Sitzungseinstellungen
- Einstellungen für die Zeitanzeige

<Info>
Die Synchronisierung erfolgt über MQTT für Echtzeit-Reaktionsfähigkeit. Befehle kommen im Online-Modus normalerweise innerhalb von Sekunden an.
</Info>

## Beheben von Offline-Problemen

<AccordionGroup>
<Accordion title="Die verbleibende Zeit wird nicht angezeigt">
Stellen Sie eine Verbindung zu WLAN her, um die Zeit zu synchronisieren. Die Sperre läuft noch – Sie können den Countdown nur erst sehen, wenn die Zeit synchronisiert ist.
</Accordion>

<Accordion title="Schlüsselhalterbefehle können nicht empfangen werden">
Ihr Gerät muss online sein, um Dashboard-Befehle zu empfangen. Überprüfen Sie den WLAN-Verbindungsstatus in der Statusleiste.
</Accordion>

<Accordion title="Die Sperre wurde beendet, aber das Dashboard zeigt immer noch „gesperrt“ an">
Das Dashboard wird aktualisiert, wenn Ihr Gerät erneut eine Verbindung herstellt. Stellen Sie eine WLAN-Verbindung her und der Status wird synchronisiert.
</Accordion>

<Accordion title="WLAN stellt die Verbindung nicht automatisch wieder her">
Gehen Sie zu Einstellungen → WLAN-Einstellungen, um die Verbindung manuell wiederherzustellen. Ihr Sperrstatus bleibt davon unberührt.
</Accordion>
</AccordionGroup>
