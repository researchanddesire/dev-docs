## Informations sur le micrologiciel

Votre appareil affiche la version de son micrologiciel sur l'écran de démarrage (par exemple, "Chastity Lockbox: 1.17.21"). Vous pouvez également trouver des informations sur la version dans Settings après le démarrage de l'appareil.

- **Canal de production** : versions stables pour un usage général
- **Canal Alpha** : versions en accès anticipé avec de nouvelles fonctionnalités (inscription via Settings → Enrol in Alpha)
