## Informations sur le micrologiciel

Votre appareil affiche la version de son micrologiciel sur l'écran de démarrage (par exemple, « Chastity Lockbox : 1.17.21 »). Vous pouvez également trouver des informations sur la version dans Paramètres après le démarrage de l'appareil.

- **Canal de production** : versions stables pour un usage général
- **Canal Alpha** : builds à accès anticipé avec de nouvelles fonctionnalités (inscription via Paramètres → S'inscrire dans Alpha)
