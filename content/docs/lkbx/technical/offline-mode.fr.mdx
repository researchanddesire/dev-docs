---
title: "Mode hors ligne"
description: "Comment fonctionne votre Chastity Lockbox lorsqu'elle n'est pas connectée au WiFi ou au tableau de bord"
---

Votre Chastity Lockbox est conçue pour fonctionner à la fois en ligne et hors ligne. Ce guide explique ce qui fonctionne sans WiFi, ce qui nécessite une connexion et comment l'appareil gère les transitions entre les états en ligne et hors ligne.

## Ce qui fonctionne hors ligne

Ces fonctionnalités fonctionnent entièrement sans connexion Internet :

| Fonctionnalité | Fonctionnement hors ligne |
|---------|-----------------|
| Verrouillages temporisés | Le minuteur continue son compte à rebours localement |
| Mécanisme de verrouillage/déverrouillage | Le verrou physique se verrouille et se déverrouille |
| Navigation dans les menus | Tous les menus sont accessibles |
| Commandes des boutons | Fonctionnalité complète |
| Modes de veille | Les modes de veille automatiques et manuels fonctionnent |
| Déverrouillage d'urgence | Peut être utilisé localement (si activé) |
| Persistance de l'état | L'état du verrouillage est conservé après les redémarrages |

<Tip>
Si vous vous rendez dans un endroit sans WiFi, votre verrou continuera de fonctionner. Le minuteur fonctionne sur l'appareil lui-même, et non sur un serveur.
</Tip>

## Ce qui nécessite le WiFi

Ces fonctionnalités nécessitent une connexion WiFi active :

| Fonctionnalité | Pourquoi le WiFi est nécessaire |
|---------|-------------------|
| Couplage | L'appareil doit s'enregistrer auprès du serveur du tableau de bord |
| Mises à jour du micrologiciel | Téléchargements depuis le serveur de mise à jour |
| Synchronisation du tableau de bord | Reçoit les commandes du détenteur de clé |
| Synchronisation de l'heure | Obtient l'heure exacte du serveur NTP |
| Journalisation des activités | Envoie les événements au tableau de bord |
| Vote public | Reçoit les mises à jour des votes |
| Déverrouillage par le détenteur de clé | Commandes de déverrouillage à distance |

## Affichage de l'heure hors ligne

Lorsque votre appareil n'est pas connecté au WiFi et n'a pas synchronisé l'heure, l'écran de verrouillage affiche :

> "Connect Wi-Fi to see time remaining"

<Warning>
Sans synchronisation de l'heure, l'appareil ne peut pas afficher avec précision le temps restant. Cependant, le minuteur de verrouillage lui-même fonctionne toujours correctement selon la durée configurée.
</Warning>

### Pourquoi cela se produit

L'appareil doit connaître l'heure actuelle pour calculer « time remaining ». Sans synchronisation NTP :
- L'appareil connaît la durée du verrouillage
- L'appareil ne sait pas quelle heure il est
- Il ne peut donc pas calculer « time remaining »

Une fois le WiFi connecté et l'heure synchronisée, l'affichage indique le temps restant avec précision.

## Mode « local play »

Lorsque vous démarrez un verrouillage directement sur l'appareil, et non depuis le tableau de bord, celui-ci fonctionne en mode « local play » :

### Caractéristiques du mode « local play »

- La durée du verrouillage est stockée localement sur l'appareil
- Le minuteur fonctionne indépendamment du serveur
- Le détenteur de clé n'a pas besoin d'intervenir
- Le verrouillage prend fin à l'expiration du minuteur

### Verrouillages du tableau de bord

Lorsqu'un verrouillage est démarré depuis le tableau de bord :

- Les paramètres sont synchronisés avec l'appareil via WiFi
- Les calendriers de pause sont reçus
- Le déverrouillage d'urgence peut être désactivé à distance
- Le détenteur de clé peut modifier le verrouillage à distance

<Info>
Les verrouillages locaux (démarrés sur l'appareil) ne peuvent pas être modifiés depuis le tableau de bord. Les verrouillages du tableau de bord peuvent être modifiés par votre détenteur de clé même hors ligne : les changements sont synchronisés lorsque vous vous reconnectez.
</Info>

## Persistance de l'état

Votre appareil conserve son état après :

- Les redémarrages
- Les cycles d'alimentation
- Les déconnexions du WiFi
- Deep sleep

Les données suivantes sont conservées :

| Données | Stockage |
|------|---------|
| État du verrouillage (verrouillé/déverrouillé) | Mémoire non volatile |
| Heure de fin du verrouillage | Mémoire non volatile |
| Paramètres de session | Mémoire non volatile |
| Identifiants WiFi | Mémoire non volatile |
| Données d'étalonnage | Mémoire non volatile |

<Note>
Même si votre appareil perd complètement son alimentation, il revient à l'état verrouillé lorsqu'il est rallumé.
</Note>

## Comportement de reconnexion au WiFi

Lorsque la connexion WiFi est interrompue pendant le fonctionnement :

1. **Immédiatement** : l'appareil continue de fonctionner normalement
2. **Toutes les 30 secondes** : tentative de reconnexion automatique
3. **À la reconnexion** : l'état est synchronisé avec le tableau de bord

### Configuration manuelle du WiFi

Vous pouvez reconfigurer le WiFi à tout moment via :
- Main Menu → Settings → WiFi Settings
- Lock Menu → WiFi Settings (while locked)

Le portail de configuration s'ouvre sans modifier l'état de votre verrouillage.

## Scénarios hors ligne

### Scénario 1 : le WiFi tombe en panne pendant un verrouillage

- Le minuteur de verrouillage continue normalement
- L'indicateur "Connecting" s'affiche dans la barre d'état
- Des tentatives de reconnexion automatique ont lieu toutes les 30 secondes
- Le verrou se déverrouille à l'expiration du minuteur (WiFi non requis)

### Scénario 2 : démarrer un verrouillage sans WiFi

- Accédez à "Lock" dans le menu
- Réglez la durée avec l'encodeur
- Appuyez sur "Enter" pour confirmer
- Le verrouillage s'active localement
- L'affichage de l'heure indique "Connect Wi-Fi to see time remaining"
- Le minuteur continue de compter à rebours correctement

### Scénario 3 : se rendre dans un endroit sans WiFi

- L'appareil fonctionne normalement
- Le tableau de bord ne peut pas envoyer de commandes
- Le déverrouillage d'urgence local reste disponible (si activé)
- Au retour sur le WiFi, l'état se synchronise automatiquement

### Scénario 4 : Deep sleep déconnecte le WiFi

- Le WiFi se déconnecte pendant Deep sleep (économie d'énergie)
- L'état du verrouillage reste inchangé
- Au réveil, le WiFi se reconnecte automatiquement
- Les commandes du tableau de bord en attente sont reçues

## Détails de la synchronisation du tableau de bord

Lorsqu'il est en ligne, votre appareil se synchronise périodiquement avec le tableau de bord :

### Sortant (appareil → tableau de bord)

- Modifications de l'état du verrouillage
- Pressions sur les boutons
- Relevés des capteurs
- Utilisation du déverrouillage d'urgence
- Timing des pauses

### Entrant (tableau de bord → appareil)

- Commandes de verrouillage
- Commandes de déverrouillage
- Mises à jour du calendrier de pause
- Modifications des paramètres de session
- Préférences d'affichage de l'heure

<Info>
La synchronisation s'effectue via MQTT pour une réactivité en temps réel. Les commandes arrivent généralement en quelques secondes lorsque l'appareil est en ligne.
</Info>

## Résoudre les problèmes hors ligne

<AccordionGroup>
<Accordion title="Le temps restant ne s'affiche pas">
Connectez-vous au WiFi pour synchroniser l'heure. Le verrouillage est toujours en cours : vous ne pouvez simplement pas voir le compte à rebours avant la synchronisation de l'heure.
</Accordion>

<Accordion title="Impossible de recevoir les commandes du détenteur de clé">
Votre appareil doit être en ligne pour recevoir les commandes du tableau de bord. Vérifiez l'état de la connexion WiFi dans la barre d'état.
</Accordion>

<Accordion title="Le verrouillage est terminé, mais le tableau de bord l'affiche toujours comme verrouillé">
Le tableau de bord se met à jour lorsque votre appareil se reconnecte. Connectez-vous au WiFi pour synchroniser l'état.
</Accordion>

<Accordion title="Le WiFi ne se reconnecte pas automatiquement">
Accédez à Settings → WiFi Settings pour vous reconnecter manuellement. L'état de votre verrouillage reste inchangé.
</Accordion>
</AccordionGroup>
