# OSSM

Verwenden Sie die [Software-Referenz](/ossm/software/getting-started/introduction) für Architektur, BLE, GPIO, Betriebsmodi, Sicherheitsfunktionen, Bewegung, Anzeige und Updates. Verwenden Sie die [Hardware-Referenz](/ossm/hardware/pcb/introduction) für die offizielle Leiterplatte und deren bekannte Probleme.

Verwenden Sie für die physische Bauabfolge [R+D Assembly](https://ohai.researchanddesire.com/ossm). Für den normalen Betrieb verwenden Sie das [OSSM-Benutzerhandbuch](https://docs.researchanddesire.com/ossm/get-started).
