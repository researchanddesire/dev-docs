# OSSM

Verwenden Sie [Software-Referenz](/ossm/software/getting-started/introduction) für Architektur, BLE, GPIO, Betriebsmodi, Sicherheitsfunktionen, Bewegung, Anzeige und Updates. Verwenden Sie [Hardware-Referenz](/ossm/hardware/pcb/introduction) für die offizielle Leiterplatte und ihre bekannten Probleme.

Verwenden Sie für die physische Build-Sequenz [R+D-Montage](https://ohai.researchanddesire.com/ossm). Für den normalen Betrieb verwenden Sie [OSSM-Benutzerhandbuch](https://docs.researchanddesire.com/ossm/get-started).
