# OSSM

Utilisez la [référence du logiciel](/ossm/software/getting-started/introduction) pour l'architecture, BLE, GPIO, les modes de fonctionnement, les fonctionnalités de sécurité, le mouvement, l'affichage et les mises à jour. Utilisez la [référence matérielle](/ossm/hardware/pcb/introduction) pour le PCB officiel et ses problèmes connus.

Pour la séquence de construction physique, utilisez [R+D Assembly](https://ohai.researchanddesire.com/ossm). Pour un fonctionnement ordinaire, utilisez le [Guide de l'utilisateur OSSM](https://docs.researchanddesire.com/ossm/get-started) .
