---
title: "Configuration de PlatformIO"
description: "Configurez PlatformIO dans VS Code pour compiler et télécharger le micrologiciel OSSM de manière fiable"
---

OSSM est construit avec PlatformIO au-dessus de VS Code. Si vous venez de l'IDE Arduino, la transition peut sembler peu familière au premier abord, mais vous obtiendrez des builds plus rapides, une meilleure gestion des dépendances et une configuration cohérente entre les contributeurs.

<Tip>
PlatformIO gère les bibliothèques, les chaînes d'outils et les environnements de construction pour vous. Les versions antérieures d'OSSM pourraient être adaptées à Arduino, mais le projet a dépassé cette approche. L'apprentissage de PlatformIO prend moins de temps que le reconditionnement d'OSSM pour Arduino à chaque version.
</Tip>

## Pourquoi PlatformIO ?

- Plus de temps pour les fonctionnalités – moins de temps à gérer les dépendances
- Collaboration plus facile : environnement de développement cohérent pour chaque contributeur
- Résolution automatique des dépendances : bibliothèques récupérées et épinglées pour des versions reproductibles
- Intelligence du code : saisie semi-automatique, peluchage et détection d'erreurs en ligne

## Conditions préalables

- VSCode installé
- Câble de données USB pour votre carte (les câbles de charge uniquement ne pourront pas être téléchargés)
- Pilotes de carte installés si votre système d'exploitation l'exige (par exemple, CP210x ou CH340)

<Note>
La carte OSSM de référence utilise un module de développement <strong>Espressif ESP32</strong> intégré.
</Note>

## Installation

<Steps>
<Step title="Installer VS Code et PlatformIO">
Installez VS Code, puis ajoutez l'extension "PlatformIO IDE" à partir de VS Code Marketplace. Après l'installation, redémarrez VS Code pour activer PlatformIO.

<Check>
Vous devriez voir l'icône PlatformIO à tête extraterrestre dans la barre d'activité à gauche.
</Check>
</Step>

<Step title="Accueil PlatformIO ouvert">
Cliquez sur l'icône PlatformIO pour ouvrir PlatformIO Home.

</Frame>

<Frame>
<img src="./_images/156351872-008e57a4-5e65-40f8-b65c-b663318317d8.webp" alt="Interface d'accueil de PlatformIO" />
</Frame>
</Step>

<Step title="Ouvrez le projet OSSM">
Depuis PlatformIO Home, sélectionnez « Ouvrir le projet » et choisissez le dossier OSSM qui contient `platformio.ini` (minuscules).

<Frame>
<img src="./_images/156352091-867148c0-e9bd-47fa-a4e9-7c99c8fce5b1.webp" alt="Ouvrir la boîte de dialogue Projet dans PlatformIO" />
</Frame>

<Frame>
<img src="./_images/156352222-e3c6c412-248e-40d5-9e7c-d3a895dd0db7.webp" alt="Sélection du dossier du projet OSSM" />
</Frame>

<Check>
L'explorateur doit afficher `platformio.ini`, un dossier `src/` et un dossier `lib/`.
</Check>
</Step>

<Step title="Sélectionnez le bon environnement (le cas échéant)">
Si le projet définit plusieurs environnements dans `platformio.ini` (par exemple, différentes cartes ou options de construction), utilisez le sélecteur d'environnement dans la barre d'état VS Code (généralement étiqueté avec l'environnement actif) pour choisir celui qui correspond à votre carte.

<Note>
S'il n'y a qu'un seul environnement, PlatformIO le sélectionne automatiquement.
</Note>
</Step>

<Step title="Ouvrez le point d'entrée du firmware">
Ouvrez `src/main.cpp` pour vérifier la source du micrologiciel.

<Frame>
<img src="./_images/4a687ec9-8110-4500-8ee7-f51c692e2403.webp" alt="fichier main.cpp dans le répertoire src" />
</Frame>
</Step>

<Step title="Construire et télécharger le firmware">
Utilisez l'icône ✓ (Build) pour compiler et l'icône → (Upload) pour flasher le tableau. Ces contrôles se trouvent dans la barre d'état en bas de VS Code.

<Frame>
<img src="./_images/156352700-12fad91c-a8d2-48fa-97cc-ee088d0ff219.webp" alt="Boutons de compilation et de téléchargement dans la barre d'état" />
</Frame>

- Créez d'abord pour détecter les erreurs localement, ou téléchargez directement pour compiler et flasher en une seule étape.
- Assurez-vous que votre carte est connectée et que le port série correct est sélectionné.

<Check>
Une build réussie se termine par `SUCCESS` dans le terminal. Un téléchargement réussi affiche `Hash of data verified` ou une confirmation similaire du téléchargeur ESP32.
</Check>
</Step>
</Steps>

## Tâches courantes

- Sélectionnez le port série : PlatformIO → Accès rapide → "Sélectionner le port série".
- Surveiller la sortie série : cliquez sur l'icône de prise (Moniteur) dans la barre d'état ou exécutez `PlatformIO: Monitor` à partir de la palette de commandes.
- Version propre : exécutez `PlatformIO: Clean` pour supprimer les artefacts compilés avant la reconstruction.

## Dépannage

<AccordionGroup>
<Accordion title="Le téléchargement échoue ou la carte n'est pas détectée">
Les causes les plus courantes sont une configuration incorrecte du port série ou de la carte.

### Vérifiez votre port série

Sous Windows, la carte apparaît sous la forme `COMx`. Sous macOS/Linux, il apparaît sous `/dev/tty.*` ou `/dev/cu.*`.

Définissez le port dans PlatformIO :

<Frame>
<img src="./_images/156354154-c71755e4-d19f-4387-bceb-743403777711.webp" alt="Sélection du port COM dans PlatformIO" />
</Frame>

<Tip>
Si vous ne voyez pas de port, essayez un autre câble USB, un autre port USB ou installez le pilote USB vers UART approprié pour votre carte.
</Tip>

<Note>
La cible de référence de la carte OSSM est **Espressif ESP32 Dev Module**. Assurez-vous que votre environnement `platformio.ini` utilise le paramètre `board` correct pour ESP32.
</Note>
</Accordion>

<Accordion title="La construction échoue en raison de mises à jour de la bibliothèque ou de la plate-forme">
Une mise à jour d'une plate-forme ou d'une bibliothèque peut introduire des modifications importantes. Épinglez les versions dans `platformio.ini` pour restaurer une configuration connue.

```ini platformio.ini
; Example: pin the Espressif32 platform
platform = espressif32@3.5.0
```

<Warning>
Vérifiez toujours les notes de version du projet pour connaître les versions de plate-forme et de bibliothèque recommandées.
</Warning>
</Accordion>

<Accordion title="Le moniteur série affiche du charabia">
Cela indique généralement une inadéquation du débit en bauds.

- Vérifiez `monitor_speed` dans `platformio.ini` (par exemple, `115200`)
- Assurez-vous que le micrologiciel et le moniteur série utilisent le même débit en bauds
</Accordion>

<Accordion title="Coincé lors de la connexion… pendant le téléchargement">
- Maintenez ou appuyez sur les boutons BOOT/EN de la carte comme requis par votre module ESP32
- Appuyez sur Réinitialiser une fois le téléchargement terminé si la carte ne redémarre pas automatiquement
- Déconnectez les autres applications susceptibles d'utiliser le même port série
</Accordion>
</AccordionGroup>

<Info>
Si vous rencontrez des problèmes non abordés ici, capturez le journal complet de création/téléchargement de PlatformIO à partir du terminal VS Code et incluez-le lorsque vous demandez de l'aide. Le journal contient l'environnement sélectionné, les versions de la plateforme et les messages d'erreur exacts.
</Info>
