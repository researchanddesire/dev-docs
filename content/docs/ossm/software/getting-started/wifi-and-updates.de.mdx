title: "WLAN und Updates"

---

Das OSSM unterstützt WLAN-Konnektivität für OTA-Firmware-Updates (Over-the-Air). In dieser Anleitung wird erklärt, wie Sie Ihr OSSM mit Ihrem Heimnetzwerk verbinden und nach Updates suchen.

## WLAN-Einrichtung

### WLAN-Einrichtung starten

<Steps>
<Step title="Navigieren Sie zu WLAN-Setup">
Scrollen Sie im Hauptmenü zu **WiFi-Setup** und drücken Sie den Encoder, um es auszuwählen.
</Step>

<Step title="Verbindungsanweisungen anzeigen">
Das Display zeigt:

- Überschrift „WiFi-Setup“.
- Anleitung zur Verbindung mit „OSSM Setup“
- Ein QR-Code für eine schnelle Verbindung

Der QR-Code kodiert: `WIFI:S:OSSM Setup;T:nopass;;`
</Step>

<Step title="Stellen Sie eine Verbindung zum OSSM-Zugangspunkt her">
Auf Ihrem Telefon oder Computer:

1. Öffnen Sie die WLAN-Einstellungen
2. Suchen Sie nach einem Netzwerk namens **OSSM Setup**
3. Verbinden (kein Passwort erforderlich)

<Tip>
Scannen Sie den QR-Code mit der Kamera Ihres Telefons, um mit unterstützten Geräten eine Verbindung mit nur einem Fingertipp herzustellen.
</Tip>
</Step>

<Step title="Konfigurieren Sie Ihr Heimnetzwerk">
Nach der Verbindung mit dem OSSM-Zugangspunkt:

1. Ein Captive-Portal sollte sich automatisch öffnen
2. Wenn nicht, öffnen Sie einen Browser und navigieren Sie zu `192.168.4.1`
3. Wählen Sie Ihr WLAN-Heimnetzwerk aus der Liste aus
4. Geben Sie Ihr WLAN-Passwort ein
5. Klicken Sie auf **Speichern**

Der OSSM wird versuchen, eine Verbindung zu Ihrem Heimnetzwerk herzustellen.
</Step>

<Step title="Beenden Sie die WLAN-Einrichtung">
Drücken Sie den Encoder oder wählen Sie **Neustart**, um den WLAN-Einrichtungsmodus zu verlassen. Der OSSM wird neu gestartet und verbindet sich mit Ihrem konfigurierten Netzwerk.
</Step>
</Steps>

### Verbindung wird überprüft

Nach dem Neustart versucht der OSSM, eine Verbindung zu Ihrem konfigurierten WLAN-Netzwerk herzustellen. Sie können die Verbindung überprüfen, indem Sie:

1. Wählen Sie im Hauptmenü **Aktualisieren** aus
2. Wenn eine WLAN-Verbindung besteht, wird „Nach Updates suchen …“ angezeigt.
3. Wenn keine WLAN-Verbindung besteht, werden Sie zur WLAN-Einrichtung weitergeleitet

<Note>
Das OSSM zeigt seine IP-Adresse nicht auf dem Bildschirm an. Für erweiterte Netzwerke können Sie es in der DHCP-Client-Liste Ihres Routers finden oder Netzwerk-Scan-Tools verwenden.
</Note>

### WLAN-Einstellungen löschen

So stellen Sie eine Verbindung zu einem anderen Netzwerk her oder beheben Verbindungsprobleme:

1. Wählen Sie **WiFi-Setup** aus dem Menü
2. Beim Speichern neuer Einstellungen wird die bisherige Netzwerkkonfiguration überschrieben
3. Alternativ können Sie die Firmware neu flashen, um alle Einstellungen zu löschen

## Over-the-Air-Updates

Der OSSM kann Firmware-Updates direkt über WLAN herunterladen und installieren, ohne eine Verbindung zu einem Computer herzustellen.

### Voraussetzungen

- Aktive WLAN-Verbindung (konfiguriert über WLAN-Setup)
- Internetzugang über Ihr Netzwerk
- Ausreichend Akku/Strom während des Aktualisierungsvorgangs

### Suche nach Updates

<Steps>
<Step title="Navigieren Sie zu „Aktualisieren“.">
Scrollen Sie im Hauptmenü zu **Aktualisieren** und drücken Sie den Encoder.
</Step>

<Step title="Warten Sie auf die Versionsprüfung">
Während das OSSM den Update-Server kontaktiert, wird auf dem Display „Checking for update...“ angezeigt.

Die Firmware sendet ihre aktuelle Version (`SW_VERSION`) an den Server, der antwortet, ob ein Update verfügbar ist.
</Step>

<Step title="Überprüfen Sie das Ergebnis">
Sie sehen einen von zwei Bildschirmen:

**Kein Update verfügbar:**
- Meldung „Kein Update verfügbar“.
- Drücken Sie den Encoder, um zum Menü zurückzukehren

**Update verfügbar:**
- Meldung „OSSM wird aktualisiert…“.
- Das Update beginnt automatisch
</Step>
</Steps>

### Während des Updates

<Warning>
Schalten Sie Ihr OSSM während eines Updates nicht aus und trennen Sie es nicht. Dies kann die Firmware beschädigen und eine manuelle Wiederherstellung erfordern.
</Warning>

Der Update-Prozess:

1. Lädt die neue Firmware-Binärdatei herunter (~1-2 MB)
2. Überprüft die Download-Integrität
3. Schreibt die Firmware in den Flash-Speicher
4. Startet das Gerät automatisch neu

Das Display zeigt: „Update läuft. Dies kann bis zu 60 Sekunden dauern.“

### Nach dem Update

Nach einem erfolgreichen Update startet der OSSM automatisch neu. Es wird:

1. Booten Sie mit der neuen Firmware
2. Führen Sie die Referenzfahrtsequenz durch
3. Zurück zum Hauptmenü

<Check>
Ihre Einstellungen und WLAN-Konfiguration bleiben bei Updates erhalten.
</Check>

### Kanäle aktualisieren

Die OSSM-Firmware unterstützt mehrere Update-Kanäle:

| Kanal | URL | Beschreibung |
|---------|-----|-------------|
| Produktion | `d2g4f7zewm360.cloudfront.net` | Stabile Versionen für den allgemeinen Gebrauch |
| Entwicklung | `d2oq8yqnezqh3r.cloudfront.net` | Vorabversionen zum Testen |

<Note>
Der Update-Kanal wird zur Kompilierzeit bestimmt. Die Produktionsfirmware überprüft den Produktionsserver. Die Entwicklungsfirmware überprüft den Entwicklungsserver.
</Note>

## Fehlerbehebung

<AccordionGroup>
<Accordion title="OSSM-Setup-Netzwerk kann nicht gefunden werden">
- Stellen Sie sicher, dass Sie sich im WLAN-Setup-Modus befinden (auf dem Bildschirm wird der QR-Code angezeigt).
- Gehen Sie näher an das OSSM heran
- Versuchen Sie, die WLAN-Liste Ihres Geräts zu aktualisieren
- Starten Sie den OSSM neu und versuchen Sie es erneut
</Accordion>

<Accordion title="Das Captive-Portal wird nicht angezeigt">
- Öffnen Sie manuell einen Browser und navigieren Sie zu `192.168.4.1`
- Deaktivieren Sie vorübergehend mobile Daten auf Ihrem Telefon
- Versuchen Sie es mit einem anderen Gerät
</Accordion>

<Accordion title="WLAN stellt keine Verbindung zum Heimnetzwerk her">
- Überprüfen Sie, ob Ihr WLAN-Passwort korrekt ist
- Stellen Sie sicher, dass Ihr Netzwerk 2,4 GHz hat (ESP32 unterstützt kein 5 GHz).
- Überprüfen Sie, ob Ihr Router neue Geräte zulässt
- Versuchen Sie, den OSSM näher an Ihren Router zu bringen
</Accordion>

<Accordion title="Die Aktualisierungsprüfung schlägt fehl">
- Überprüfen Sie, ob eine WLAN-Verbindung besteht (versuchen Sie es zuerst mit der WLAN-Einrichtung).
- Überprüfen Sie Ihre Internetverbindung
- Der Update-Server ist möglicherweise vorübergehend nicht verfügbar
- Versuchen Sie es in ein paar Minuten noch einmal
</Accordion>

<Accordion title="Der Update-Download schlägt fehl oder es kommt zu einer Zeitüberschreitung">
- Stellen Sie während des Updates ein stabiles WLAN-Signal sicher
- Gehen Sie bei Bedarf näher an Ihren Router heran
- Stellen Sie sicher, dass Ihre Internetverbindung funktioniert
- Versuchen Sie es erneut mit einem neuen Stromanschluss
</Accordion>

<Accordion title="OSSM startet nach dem Update nicht">
Dies ist selten, kann aber passieren, wenn das Update unterbrochen wurde. Wiederherstellungsoptionen:

1. Versuchen Sie, das Gerät aus- und wieder einzuschalten (Netzstecker ziehen und wieder einstecken).
2. Wenn das Gerät nicht startet, müssen Sie über USB mit [PlattformIO](/ossm/software/getting-started/platformio) neu flashen
</Accordion>
</AccordionGroup>

## Technische Details

### Serverkommunikation aktualisieren

Der OSSM sendet eine POST-Anfrage an den Update-Server mit:

```json
{
  "ossmSwVersion": "x.y.z"
}
```

Der Server antwortet mit:

```json
{
  "response": {
    "needUpdate": true
  }
}
```

Wenn `needUpdate` `true` ist, lädt die Firmware die Binärdatei vom Firmware-Verteilungsserver herunter.

### Firmware-Binärspeicherorte

| Kanal | Binäre URL |
|---------|------------|
| Produktion | `d2sy3zdr3r1gt5.cloudfront.net/firmware.bin` |
| Entwicklung | `d2sy3zdr3r1gt5.cloudfront.net/firmware-dev.bin` |
