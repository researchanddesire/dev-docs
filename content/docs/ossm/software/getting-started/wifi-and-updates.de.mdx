---

Das OSSM unterstützt WiFi-Konnektivität für Over-the-Air-(OTA-)Firmware-Updates. In dieser Anleitung wird erklärt, wie Sie Ihr OSSM mit Ihrem Heimnetzwerk verbinden und nach Updates suchen.

## WiFi-Einrichtung

### WiFi-Einrichtung starten

<Steps>
<Step title="Navigieren Sie zu WiFi Setup">
Scrollen Sie im Hauptmenü zu **WiFi Setup** und drücken Sie den Encoder, um es auszuwählen.
</Step>

<Step title="Verbindungsanweisungen anzeigen">
Das Display zeigt:

- Überschrift "WiFi Setup"
- Anleitung zur Verbindung mit "OSSM Setup"
- Ein QR-Code für eine schnelle Verbindung

Der QR-Code kodiert: `WIFI:S:OSSM Setup;T:nopass;;`
</Step>

<Step title="Stellen Sie eine Verbindung zum OSSM-Zugangspunkt her">
Auf Ihrem Telefon oder Computer:

1. Öffnen Sie die WiFi-Einstellungen
2. Suchen Sie nach einem Netzwerk namens **OSSM Setup**
3. Verbinden Sie sich (kein Passwort erforderlich)

<Tip>
Scannen Sie den QR-Code mit der Kamera Ihres Telefons, um mit unterstützten Geräten eine Verbindung mit nur einem Fingertipp herzustellen.
</Tip>
</Step>

<Step title="Konfigurieren Sie Ihr Heimnetzwerk">
Nach der Verbindung mit dem OSSM-Zugangspunkt:

1. Ein Captive-Portal sollte sich automatisch öffnen
2. Wenn nicht, öffnen Sie einen Browser und navigieren Sie zu `192.168.4.1`
3. Wählen Sie Ihr WiFi-Heimnetzwerk aus der Liste aus
4. Geben Sie Ihr WiFi-Passwort ein
5. Klicken Sie auf **Save**

Das OSSM wird versuchen, eine Verbindung zu Ihrem Heimnetzwerk herzustellen.
</Step>

<Step title="Beenden Sie die WiFi-Einrichtung">
Drücken Sie den Encoder oder wählen Sie **Restart**, um den WiFi-Einrichtungsmodus zu verlassen. Das OSSM wird neu gestartet und verbindet sich mit Ihrem konfigurierten Netzwerk.
</Step>
</Steps>

### Verbindung überprüfen

Nach dem Neustart versucht das OSSM, eine Verbindung zu Ihrem konfigurierten WiFi-Netzwerk herzustellen. Sie können die Verbindung wie folgt überprüfen:

1. Wählen Sie im Hauptmenü **Update** aus
2. Wenn eine WiFi-Verbindung besteht, wird "Checking for update..." angezeigt.
3. Wenn keine WiFi-Verbindung besteht, werden Sie zur WiFi-Einrichtung weitergeleitet

<Note>
Das OSSM zeigt seine IP-Adresse nicht auf dem Bildschirm an. Für erweiterte Netzwerkkonfigurationen können Sie sie in der DHCP-Client-Liste Ihres Routers finden oder Netzwerk-Scan-Tools verwenden.
</Note>

### WiFi-Einstellungen löschen

So stellen Sie eine Verbindung zu einem anderen Netzwerk her oder beheben Verbindungsprobleme:

1. Wählen Sie **WiFi Setup** aus dem Menü
2. Beim Speichern neuer Einstellungen wird die bisherige Netzwerkkonfiguration überschrieben
3. Alternativ können Sie die Firmware neu flashen, um alle Einstellungen zu löschen

## Over-the-air-Updates

Das OSSM kann Firmware-Updates direkt über WiFi herunterladen und installieren, ohne eine Verbindung zu einem Computer herzustellen.

### Voraussetzungen

- Aktive WiFi-Verbindung (konfiguriert über WiFi Setup)
- Internetzugang über Ihr Netzwerk
- Ausreichender Akkustand bzw. eine ausreichende Stromversorgung während des Updates

### Suche nach Updates

<Steps>
<Step title="Navigieren Sie zu Update">
Scrollen Sie im Hauptmenü zu **Update** und drücken Sie den Encoder.
</Step>

<Step title="Warten Sie auf die Versionsprüfung">
Während das OSSM den Update-Server kontaktiert, wird auf dem Display "Checking for update..." angezeigt.

Die Firmware sendet ihre aktuelle Version (`SW_VERSION`) an den Server, der meldet, ob ein Update verfügbar ist.
</Step>

<Step title="Überprüfen Sie das Ergebnis">
Sie sehen einen von zwei Bildschirmen:

**Kein Update verfügbar:**
- Meldung "No Update Available"
- Drücken Sie den Encoder, um zum Menü zurückzukehren

**Update verfügbar:**
- Meldung "Updating OSSM..."
- Das Update beginnt automatisch
</Step>
</Steps>

### Während des Updates

<Warning>
Schalten Sie Ihr OSSM während eines Updates nicht aus und trennen Sie es nicht von der Stromversorgung. Dies kann die Firmware beschädigen und eine manuelle Wiederherstellung erfordern.
</Warning>

Der Update-Prozess:

1. Lädt die neue Firmware-Binärdatei herunter (~1-2 MB)
2. Überprüft die Download-Integrität
3. Schreibt die Firmware in den Flash-Speicher
4. Startet das Gerät automatisch neu

Das Display zeigt: "Update is in progress. This may take up to 60s."

### Nach dem Update

Nach einem erfolgreichen Update startet das OSSM automatisch neu. Es wird:

1. mit der neuen Firmware starten
2. die Referenzfahrt durchführen
3. zum Hauptmenü zurückkehren

<Check>
Ihre Einstellungen und WiFi-Konfiguration bleiben bei Updates erhalten.
</Check>

### Update-Kanäle

Das OSSM unterstützt mehrere Update-Kanäle:

| Kanal | URL | Beschreibung |
|---------|-----|-------------|
| Production | `d2g4f7zewm360.cloudfront.net` | Stabile Versionen für den allgemeinen Gebrauch |
| Development | `d2oq8yqnezqh3r.cloudfront.net` | Vorabversionen zum Testen |

<Note>
Der Update-Kanal wird zur Kompilierzeit bestimmt. Die Production-Firmware überprüft den Production-Server; die Development-Firmware überprüft den Development-Server.
</Note>

## Fehlerbehebung

<AccordionGroup>
<Accordion title="OSSM Setup-Netzwerk kann nicht gefunden werden">
- Stellen Sie sicher, dass Sie sich im WiFi Setup-Modus befinden (auf dem Bildschirm wird der QR-Code angezeigt).
- Gehen Sie näher an das OSSM heran
- Versuchen Sie, die WiFi-Liste Ihres Geräts zu aktualisieren
- Starten Sie das OSSM neu und versuchen Sie es erneut
</Accordion>

<Accordion title="Das Captive-Portal wird nicht angezeigt">
- Öffnen Sie manuell einen Browser und navigieren Sie zu `192.168.4.1`
- Deaktivieren Sie vorübergehend mobile Daten auf Ihrem Telefon
- Versuchen Sie es mit einem anderen Gerät
</Accordion>

<Accordion title="WiFi stellt keine Verbindung zum Heimnetzwerk her">
- Überprüfen Sie, ob Ihr WiFi-Passwort korrekt ist
- Stellen Sie sicher, dass Ihr Netzwerk das 2,4-GHz-Band nutzt (ESP32 unterstützt kein 5-GHz-Band).
- Überprüfen Sie, ob Ihr Router neue Geräte zulässt
- Versuchen Sie, das OSSM näher an Ihren Router zu bringen
</Accordion>

<Accordion title="Die Aktualisierungsprüfung schlägt fehl">
- Überprüfen Sie, ob eine WiFi-Verbindung besteht (versuchen Sie es zuerst mit WiFi Setup).
- Überprüfen Sie Ihre Internetverbindung
- Der Update-Server ist möglicherweise vorübergehend nicht verfügbar
- Versuchen Sie es in ein paar Minuten noch einmal
</Accordion>

<Accordion title="Der Update-Download schlägt fehl oder es kommt zu einer Zeitüberschreitung">
- Stellen Sie während des Updates ein stabiles WiFi-Signal sicher
- Gehen Sie bei Bedarf näher an Ihren Router heran
- Stellen Sie sicher, dass Ihre Internetverbindung funktioniert
- Schließen Sie die Stromversorgung neu an und versuchen Sie es erneut
</Accordion>

<Accordion title="OSSM startet nach dem Update nicht">
Dies ist selten, kann aber passieren, wenn das Update unterbrochen wurde. Wiederherstellungsoptionen:

1. Versuchen Sie, das Gerät aus- und wieder einzuschalten (Netzstecker ziehen und wieder einstecken).
2. Wenn das Gerät nicht startet, müssen Sie über USB mit [PlatformIO](/ossm/software/getting-started/platformio) neu flashen
</Accordion>
</AccordionGroup>

## Technische Details

### Kommunikation mit dem Update-Server

Das OSSM sendet eine POST-Anfrage an den Update-Server mit:

```json
{
  "ossmSwVersion": "x.y.z"
}
```

Der Server antwortet mit:

```json
{
  "response": {
    "needUpdate": true
  }
}
```

Wenn `needUpdate` `true` ist, lädt die Firmware die Binärdatei vom Firmware-Verteilungsserver herunter.

### Speicherorte der Firmware-Binärdateien

| Kanal | URL der Binärdatei |
|---------|------------|
| Production | `d2sy3zdr3r1gt5.cloudfront.net/firmware.bin` |
| Development | `d2sy3zdr3r1gt5.cloudfront.net/firmware-dev.bin` |
