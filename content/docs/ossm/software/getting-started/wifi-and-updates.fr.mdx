---

L'OSSM prend en charge la connectivité WiFi pour les mises à jour du micrologiciel par liaison radio (OTA). Ce guide explique comment connecter votre OSSM à votre réseau domestique et vérifier les mises à jour.

## Configuration Wi-Fi

### Démarrage de la configuration Wi-Fi

<Steps>
<Step title="Accédez à la configuration WiFi">
Dans le menu principal, faites défiler jusqu'à **Configuration WiFi** et appuyez sur l'encodeur pour le sélectionner.
</Step>

<Step title="Afficher les instructions de connexion">
L'écran affiche :

- En-tête « Configuration WiFi »
- Instructions pour se connecter à « Configuration OSSM »
- Un QR code pour une connexion rapide

Le code QR code : `WIFI:S:OSSM Setup;T:nopass;;`
</Step>

<Step title="Connectez-vous au point d'accès OSSM">
Sur votre téléphone ou ordinateur :

1. Ouvrir les paramètres Wi-Fi
2. Recherchez un réseau nommé **OSSM Setup**
3. Connectez-vous (aucun mot de passe requis)

<Tip>
Scannez le code QR avec l'appareil photo de votre téléphone pour une connexion en un seul clic sur les appareils pris en charge.
</Tip>
</Step>

<Step title="Configurez votre réseau domestique">
Après vous être connecté au point d'accès OSSM :

1. Un portail captif devrait s'ouvrir automatiquement
2. Sinon, ouvrez un navigateur et accédez à `192.168.4.1`.
3. Sélectionnez votre réseau WiFi domestique dans la liste
4. Entrez votre mot de passe WiFi
5. Cliquez sur **Enregistrer**

L'OSSM tentera de se connecter à votre réseau domestique.
</Step>

<Step title="Quitter la configuration WiFi">
Appuyez sur l'encodeur ou sélectionnez **Redémarrer** pour quitter le mode de configuration WiFi. L'OSSM redémarrera et se connectera à votre réseau configuré.
</Step>
</Steps>

### Vérification de la connexion

Après le redémarrage, l'OSSM tentera de se connecter à votre réseau WiFi configuré. Vous pouvez vérifier la connexion en :

1. Sélection de **Mise à jour** dans le menu principal
2. Si le WiFi est connecté, vous verrez "Vérification des mises à jour..."
3. Si le WiFi n'est pas connecté, vous serez redirigé vers la configuration WiFi

<Note>
L'OSSM n'affiche pas son adresse IP à l'écran. Pour une mise en réseau avancée, vous pouvez le trouver dans la liste des clients DHCP de votre routeur ou utiliser des outils d'analyse réseau.
</Note>

### Effacement des paramètres Wi-Fi

Pour vous connecter à un autre réseau ou résoudre les problèmes de connexion :

1. Sélectionnez **Configuration WiFi** dans le menu
2. La configuration réseau précédente sera écrasée lorsque vous enregistrerez de nouveaux paramètres
3. Vous pouvez également reflasher le firmware pour effacer tous les paramètres

## Mises à jour en direct

L'OSSM peut télécharger et installer les mises à jour du micrologiciel directement via WiFi, sans se connecter à un ordinateur.

### Conditions préalables

- Connexion WiFi active (configurée via WiFi Setup)
- Accès Internet depuis votre réseau
- Batterie/puissance suffisante pendant le processus de mise à jour

### Vérification des mises à jour

<Steps>
<Step title="Accédez à Mettre à jour">
Dans le menu principal, faites défiler jusqu'à **Mise à jour** et appuyez sur l'encodeur.
</Step>

<Step title="Attendez la vérification de la version">
L'écran affiche "Vérification de la mise à jour..." pendant que l'OSSM contacte le serveur de mise à jour.

Le micrologiciel envoie sa version actuelle (`SW_VERSION`) au serveur, qui répond si une mise à jour est disponible.
</Step>

<Step title="Résultat de l'examen">
Vous verrez l'un des deux écrans :

**Aucune mise à jour disponible :**
- Message « Aucune mise à jour disponible »
- Appuyez sur l'encodeur pour revenir au menu

**Mise à jour disponible :**
- Message "Mise à jour d'OSSM..."
- La mise à jour démarre automatiquement
</Step>
</Steps>

### Pendant la mise à jour

<Warning>
N'éteignez pas et ne déconnectez pas votre OSSM pendant une mise à jour. Cela peut corrompre le micrologiciel et nécessiter une récupération manuelle.
</Warning>

Le processus de mise à jour :

1. Télécharge le nouveau binaire du firmware (~ 1-2 Mo)
2. Vérifie l'intégrité du téléchargement
3. Écrit le firmware dans la mémoire flash
4. Redémarre automatiquement l'appareil

L'écran affiche : "La mise à jour est en cours. Cela peut prendre jusqu'à 60 s."

### Après la mise à jour

L'OSSM redémarre automatiquement après une mise à jour réussie. Ce sera:

1. Démarrez avec le nouveau firmware
2. Effectuer la séquence de référence
3. Retour au menu principal

<Check>
Vos paramètres et votre configuration WiFi sont conservés lors des mises à jour.
</Check>

### Mettre à jour les chaînes

Le firmware OSSM prend en charge plusieurs canaux de mise à jour :

| Canal | URL | Description |
|---------|-----|-------------|
| Production | `d2g4f7zewm360.cloudfront.net` | Versions stables pour un usage général |
| Développement | `d2oq8yqnezqh3r.cloudfront.net` | Versions préliminaires pour les tests |

<Note>
Le canal de mise à jour est déterminé au moment de la compilation. Le micrologiciel de production vérifie le serveur de production ; le micrologiciel de développement vérifie le serveur de développement.
</Note>

## Dépannage

<AccordionGroup>
<Accordion title="Impossible de trouver le réseau de configuration OSSM">
- Assurez-vous que vous êtes en mode de configuration WiFi (l'écran affiche le code QR)
- Se rapprocher de l'OSSM
- Essayez d'actualiser la liste WiFi de votre appareil
- Redémarrez l'OSSM et réessayez
</Accordion>

<Accordion title="Le portail captif n'apparaît pas">
- Ouvrez un navigateur manuellement et accédez à `192.168.4.1`
- Désactivez temporairement les données mobiles sur votre téléphone
- Essayez un autre appareil
</Accordion>

<Accordion title="Le WiFi ne se connecte pas au réseau domestique">
- Vérifiez que votre mot de passe WiFi est correct
- Assurez-vous que votre réseau est à 2,4 GHz (l'ESP32 ne prend pas en charge 5 GHz)
- Vérifiez que votre routeur autorise les nouveaux appareils
- Essayez de rapprocher l'OSSM de votre routeur
</Accordion>

<Accordion title="La vérification de la mise à jour échoue">
- Vérifiez que le WiFi est connecté (essayez d'abord la configuration WiFi)
- Vérifiez votre connexion Internet
- Le serveur de mise à jour peut être temporairement indisponible
- Réessayez dans quelques minutes
</Accordion>

<Accordion title="Le téléchargement de la mise à jour échoue ou expire">
- Assurer un signal WiFi stable pendant la mise à jour
- Rapprochez-vous de votre routeur si nécessaire
- Vérifiez que votre connexion Internet fonctionne
- Réessayez avec une nouvelle connexion électrique
</Accordion>

<Accordion title="OSSM ne démarre pas après la mise à jour">
Ceci est rare mais peut arriver si la mise à jour a été interrompue. Options de récupération :

1. Essayez de redémarrer (débrancher et rebrancher l'alimentation)
2. Si l'appareil ne démarre pas, vous devrez reflasher via USB en utilisant [PlatformIO](/ossm/software/getting-started/platformio)
</Accordion>
</AccordionGroup>

## Détails techniques

### Mettre à jour la communication du serveur

L'OSSM envoie une requête POST au serveur de mise à jour avec :

```json
{
  "ossmSwVersion": "x.y.z"
}
```

Le serveur répond par :

```json
{
  "response": {
    "needUpdate": true
  }
}
```

Si `needUpdate` est `true`, le micrologiciel télécharge le binaire à partir du serveur de distribution du micrologiciel.

### Emplacements binaires du micrologiciel

| Canal | URL binaire |
|---------|------------|
| Production | `d2sy3zdr3r1gt5.cloudfront.net/firmware.bin` |
| Développement | `d2sy3zdr3r1gt5.cloudfront.net/firmware-dev.bin` |
