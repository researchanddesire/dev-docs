# Draag OSSM-documentatie bij

Gebruik het potlood naast een bewerkbare paginatitel of sectiekop om de exacte bronregel in `researchanddesire/dev-docs` te openen. GitHub begeleidt u bij het voorstellen van de wijziging in `main` als een beoordeeld pull-verzoek.

Lees de canonieke [gids voor documentatiebijdragen](/contributing) voor repository-toewijzing, optionele lokale previews, validatie, licentieverlening en het bidirectionele synchronisatieproces.

OSSM-consumenteninstructies horen thuis in de [Gebruikershandleidingen](https://docs.researchanddesire.com/ossm), terwijl fysieke bouwprocedures thuishoren in [R+D-assemblage](https://ohai.researchanddesire.com/ossm). Houd dit gedeelte gericht op ondersteunde firmware, protocollen, softwarearchitectuur en hardware-interfaces.
