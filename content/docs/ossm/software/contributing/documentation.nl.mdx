# Draag OSSM-documentatie bij

Gebruik het potlood naast een bewerkbare paginatitel of sectiekop om de exacte bronregel in `researchanddesire/dev-docs` te openen. GitHub begeleidt u bij het indienen van de wijziging in `main` als pull request voor beoordeling.

Lees de canonieke [handleiding voor bijdragen aan de documentatie](/contributing) voor de repositoryindeling, optionele lokale previews, validatie, licenties en het bidirectionele synchronisatieproces.

Instructies voor OSSM-gebruikers staan in de [Gebruikershandleidingen](https://docs.researchanddesire.com/ossm), terwijl fysieke bouwprocedures in [R+D-assemblage](https://ohai.researchanddesire.com/ossm) staan. Houd dit gedeelte gericht op ondersteunde firmware, protocollen, softwarearchitectuur en hardware-interfaces.
