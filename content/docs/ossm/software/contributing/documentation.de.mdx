# Zur OSSM-Dokumentation beitragen

Klicken Sie neben dem Titel einer bearbeitbaren Seite oder einer Abschnittsüberschrift auf den Bleistift, um die entsprechende Quellzeile in `researchanddesire/dev-docs` zu öffnen. GitHub führt Sie durch das Einreichen der Änderung in `main` als geprüften Pull Request.

Lesen Sie den maßgeblichen [Leitfaden zum Beitragen zur Dokumentation](/contributing) für die Zuordnung des Repositorys, optionale lokale Vorschauen, Validierung, Lizenzierung und den bidirektionalen Synchronisierungsprozess.

Anleitungen für OSSM-Nutzer gehören in die [Benutzerhandbücher](https://docs.researchanddesire.com/ossm), während physische Bauanleitungen zu [R+D Assembly](https://ohai.researchanddesire.com/ossm) gehören. Dieser Abschnitt konzentriert sich auf unterstützte Firmware, Protokolle, Softwarearchitektur und Hardwareschnittstellen.
