# Tragen Sie zur OSSM-Dokumentation bei

Verwenden Sie den Bleistift neben einem bearbeitbaren Seitentitel oder einer Abschnittsüberschrift, um die genaue Quellzeile in `researchanddesire/dev-docs` zu öffnen. GitHub führt Sie durch den Vorschlag der Änderung an `main` als überprüfte Pull-Anfrage.

Lesen Sie den kanonischen [Dokumentationsbeitragsleitfaden](/contributing) für Repository-Zuordnung, optionale lokale Vorschauen, Validierung, Lizenzierung und den bidirektionalen Synchronisierungsprozess.

OSSM-Consumer-Anweisungen gehören zu [Benutzerhandbücher](https://docs.researchanddesire.com/ossm), während physische Build-Prozeduren zu [R+D-Montage](https://ohai.researchanddesire.com/ossm) gehören. Konzentrieren Sie sich in diesem Abschnitt auf unterstützte Firmware, Protokolle, Softwarearchitektur und Hardwareschnittstellen.
