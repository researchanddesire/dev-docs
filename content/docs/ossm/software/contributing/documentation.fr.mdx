# Contribuer à la documentation OSSM

Utilisez le crayon situé à côté de tout titre de page ou en-tête de section modifiable pour ouvrir la ligne source correspondante dans `researchanddesire/dev-docs`. GitHub vous guidera pour proposer la modification vers `main` sous la forme d’une pull request soumise à revue.

Consultez le [guide canonique de contribution à la documentation](/contributing) pour connaître l’organisation du dépôt, les aperçus locaux facultatifs, la validation, les licences et le processus de synchronisation bidirectionnelle.

Les instructions destinées aux utilisateurs de l’OSSM figurent dans les [Guides utilisateur](https://docs.researchanddesire.com/ossm), tandis que les procédures de construction physique figurent dans l’[assemblage R+D](https://ohai.researchanddesire.com/ossm). Gardez cette section centrée sur les micrologiciels pris en charge, les protocoles, l’architecture logicielle et les interfaces matérielles.
