# Contribuer à la documentation OSSM

Utilisez le crayon à côté de tout titre de page ou en-tête de section modifiable pour ouvrir sa ligne source exacte dans `researchanddesire/dev-docs`. GitHub vous guidera dans la proposition de modification de `main` sous forme de demande d'extraction examinée.

Lisez le [guide de contribution à la documentation](/contributing) canonique  pour le mappage du référentiel, les aperçus locaux facultatifs, la validation, les licences et le processus de synchronisation bidirectionnelle.

Les instructions du consommateur OSSM appartiennent aux [Guides de l'utilisateur](https://docs.researchanddesire.com/ossm) , tandis que les procédures de construction physique appartiennent à l'[Assemblage R+D](https://ohai.researchanddesire.com/ossm) . Gardez cette section centrée sur les micrologiciels, les protocoles, l'architecture logicielle et les interfaces matérielles pris en charge.
