## Aperçu

Le service d'affichage est un wrapper global et thread-safe autour du pilote U8G2 pour un OLED SSD1306 128 × 64. Vous l'utilisez pour restituer le texte et les graphiques de n'importe quelle tâche sans scintillement ni déchirure. Un mutex FreeRTOS garantit un accès exclusif pendant que vous dessinez ; les fonctions d'assistance gèrent la suppression de région, l'actualisation partielle, le découpage et la mise en cache de texte.

<Info>
Cette page documente l'API de développement au niveau du micrologiciel utilisée sur nos appareils. Pour connaître le comportement de l'affichage destiné à l'utilisateur (par exemple, masquer les écrans de temps restant ou d'état de l'appareil), consultez les pages associées à la fin.
</Info>

## Conditions préalables

- ESP32 avec matériel I2C disponible
- Bibliothèque U8G2 intégrée à votre build de firmware
- FreeRTOS (pour le mutex d'affichage)
- Broches configurées pour SDA/SCL dans le `Pins.h` de votre carte

## Configuration matérielle

| Propriété | Valeur |
|---|---|
| Afficher | SSD1306 OLED |
| Résolution | 128×64 pixels |
| Interface | I2C (matériel) |
| Rotation | U8G2_R0 (0°) |
| Adresse I2C | 0x3C |
| Contraste | 255 (maximum) |

<Note>
Certains constructeurs U8G2 attendent l'adresse I2C 8 bits. Si tel est le cas, transmettez `0x3C << 1`. Vérifiez que cela correspond à la signature de votre constructeur.
</Note>

## Modèle de mise en page

L'écran est traité comme une grille de cellules de 8 × 8 pixels :

- Grille : 8 lignes × 16 colonnes
- Origine : (0,0) en haut à gauche
- Taille de cellule : 8 × 8 pixels

### Régions

<AccordionGroup>
<Accordion title="En-tête (ligne 0)">
- Cellules 0 à 12 : texte d'en-tête (13 cellules = 104 px)
- Cellules 13 à 15 : icônes d'état (3 cellules = 24 px)
</Accordion>

<Accordion title="Zone de page (lignes 1 à 6)">
- 6 lignes de hauteur (48 px)
- 16 cellules de large (128 px)
- Tout le contenu principal devrait s'afficher ici
</Accordion>

<Accordion title="Pied de page (ligne 7)">
- Cellules 0 à 14 : texte de pied de page (15 cellules = 120 px)
- Cellule 15 : indicateur de délai d'attente (1 cellule = 8 px)
</Accordion>
</AccordionGroup>

<Tip>
Les API de texte U8G2 utilisent la ligne de base pour `y`. Pour les polices de 8 pixels de hauteur, commencez la première ligne de texte à `y = 8`, puis ajoutez la montée/hauteur de ligne de la police pour les lignes suivantes.
</Tip>

## Sécurité du fil

Le service d'affichage expose un mutex FreeRTOS. Verrouillez toujours avant de dessiner et déverrouillez lorsque vous avez terminé.

```cpp display_mutex.h
#pragma once
#include <freertos/FreeRTOS.h>
#include <freertos/semphr.h>

extern SemaphoreHandle_t displayMutex;
```

<Warning>
Si vous ne parvenez pas à libérer le mutex, toutes les autres tâches nécessitant l'affichage seront bloquées. Associez toujours un `xSemaphoreTake` réussi avec un `xSemaphoreGive` dans un chemin de style `finally`.
</Warning>

### Modèle d'utilisation de base

```cpp example_usage.cpp
// Acquire, draw, refresh affected region(s), release
if (xSemaphoreTake(displayMutex, portMAX_DELAY) == pdTRUE) {
  // ... drawing commands, e.g.:
  display.drawStr(x, y, "HELLO WORLD");

  // Call an appropriate refresh helper (see below)
  refreshPage();

  xSemaphoreGive(displayMutex);
}
```

## Initialisation

Appelez `initDisplay()` une fois au démarrage.

```cpp display_init.h
#pragma once
void initDisplay();
```

<Steps>
<Step title="Créer des ressources et configurer le panneau">
`initDisplay()` crée le mutex d'affichage, initialise l'instance d'affichage U8G2, définit l'adressage/rotation/contraste et efface le tampon.

<Check>
Après l'initialisation, l'écran doit être vide et rétroéclairé, et `displayMutex` doit être non nul.
</Check>
</Step>

<Step title="Vérifier le dessin">
Afficher une seule ligne de texte dans la zone de la page.

```cpp sanity_check.cpp
if (xSemaphoreTake(displayMutex, portMAX_DELAY) == pdTRUE) {
  clearPage();
  display.setFont(u8g2_font_spleen5x8_mu);
  display.drawStr(0, 16, "SANITY PASS");
  refreshPage();
  xSemaphoreGive(displayMutex);
}
```
</Step>
</Steps>

## Aides au déblaiement

Effacez efficacement uniquement ce que vous envisagez de redessiner. Tous les assistants utilisent un `updateDisplayArea()` interne pour effectuer une actualisation partielle de la région affectée.

| Fonction | Description | Région effacée |
|---|---|---|
| `clearHeader()` | Efface uniquement le texte de l'en-tête | Ligne 0, cellules 0 à 12 |
| `clearIcons()` | Efface uniquement la zone d'icône | Ligne 0, cellules 13 à 15 |
| `clearFooter()` | Efface uniquement le texte du pied de page | Ligne 7, cellules 0 à 14 |
| `clearTimeout()` | Efface l'indicateur de délai d'attente | Ligne 7, cellule 15 |
| `clearPage(includeFooter=false, includeHeader=false)` | Efface la zone de la page ; en-tête/pied de page en option | Lignes 1 à 6 (plus en-tête/pied de page sur demande) |

```cpp clear_helpers.h
void clearHeader();
void clearIcons();
void clearFooter();
void clearTimeout();
void clearPage(bool includeFooter = false, bool includeHeader = false);
```

<Note>
`clearPage()` définit une fenêtre de découpage pour empêcher le contenu de se répandre dans l'en-tête ou le pied de page.
</Note>

## Actualiser les assistants

Appelez un assistant d'actualisation après avoir modifié une région. Ceux-ci effectuent des mises à jour minimales de l’affichage.

| Fonction | Description | Région mise à jour |
|---|---|---|
| `refreshHeader()` | Pousse le texte d'en-tête | Ligne 0, cellules 0 à 12 |
| `refreshIcons()` | Pousse la zone d'icône | Ligne 0, cellules 13 à 15 |
| `refreshFooter()` | Pousse le texte du pied de page | Ligne 7, cellules 0 à 14 |
| `refreshTimeout()` | Pousse l'indicateur de délai d'attente | Ligne 7, cellule 15 |
| `refreshPage(includeFooter=false, includeHeader=false)` | Pousse le contenu principal ; en-tête/pied de page en option | Lignes 1 à 6 (plus en-tête/pied de page sur demande) |

```cpp refresh_helpers.h
void refreshHeader();
void refreshIcons();
void refreshFooter();
void refreshTimeout();
void refreshPage(bool includeFooter = false, bool includeHeader = false);
```

## Aides au contenu

### `setHeader()`

Définit le texte de l'en-tête. Le service met en majuscule et met en cache la dernière valeur pour éviter les redessins redondants.

```cpp header.h
void setHeader(String &text);
```

<Tip>
Si vous appelez `setHeader()` avec la même valeur, le service ignore le dessin et l'actualisation.
</Tip>

### `setFooter()`

Définit le texte du pied de page aligné à gauche et à droite. Les deux sont en majuscules et mis en cache.

```cpp footer.h
void setFooter(String &left, String &right);
```

- La chaîne gauche s'aligne sur le bord gauche de la région du pied de page
- La chaîne droite s'aligne sur le bord droit de la région du pied de page

### `drawWrappedText()`

Dessinez du texte avec retour à la ligne automatique et alignement central en option.

```cpp wrapped_text.h
int drawWrappedText(int x, int y, const String &text, bool center = false);
```

<ParamField path="x" type="int" required>
Coordonnée x de départ en pixels.
</ParamField>
<ParamField path="y" type="int" required>
Coordonnée y de base de départ en pixels.
</ParamField>
<ParamField path="text" type="String" required>
Texte à restituer. Prend en charge le littéral `\n` pour les sauts de ligne.
</ParamField>
<ParamField path="center" type="bool" default="false">
Centrez chaque ligne enveloppée dans la zone de page lorsque `true`.
</ParamField>

<ResponseField name="return" type="int" required>
Nombre de lignes tracées.
</ResponseField>

## Modèles courants

### Dessiner un écran complet

```cpp draw_screen.cpp
if (xSemaphoreTake(displayMutex, portMAX_DELAY) == pdTRUE) {
  clearPage();
  display.setFont(u8g2_font_spleen5x8_mu);
  display.drawStr(0, 16, "MAIN CONTENT");
  refreshPage();
  xSemaphoreGive(displayMutex);
}
```

<Check>
Ce modèle efface uniquement la zone de la page, dessine du nouveau contenu et effectue une actualisation partielle pour plus de rapidité.
</Check>

### Mettre à jour l'en-tête uniquement

```cpp update_header.cpp
if (xSemaphoreTake(displayMutex, portMAX_DELAY) == pdTRUE) {
  String headerText = "NEW HEADER"; // case‑insensitive; will be uppercased
  setHeader(headerText);
  // setHeader internally decides whether a refresh is required
  xSemaphoreGive(displayMutex);
}
```

### Dessiner du texte enveloppé et centré

```cpp wrapped_text.cpp
if (xSemaphoreTake(displayMutex, portMAX_DELAY) == pdTRUE) {
  clearPage();
  int lines = drawWrappedText(0, 16, "Long text that will wrap", /*center=*/true);
  (void)lines; // optionally use the line count
  refreshPage();
  xSemaphoreGive(displayMutex);
}
```

## Directives de dessin

<Steps>
<Step title="Verrouillez le mutex pour chaque séquence de dessin">
Enveloppez le dessin et actualisez-le dans une section critique gardée par `displayMutex`.

```cpp lock_and_draw.cpp
if (xSemaphoreTake(displayMutex, portMAX_DELAY) == pdTRUE) {
  // Drawing
  xSemaphoreGive(displayMutex);
}
```
</Step>

<Step title="Préférez les aides régionales aux effacements complets">
Minimisez le trafic de bus et le scintillement en utilisant les assistants `clear*()` et `refresh*()`.

<CodeGroup>
```cpp Recommended
clearPage();
display.drawStr(0, 16, "Content");
refreshPage();
```

```cpp Avoid
// Full‑buffer clears cost time and cause visible flicker
// display.clearBuffer();
```
</CodeGroup>
</Step>

<Step title="Respecter les limites">
Conserver le contenu dans :

- En-tête : ligne 0, cellules 0 à 12
- Icônes : ligne 0, cellules 13 à 15
- Page : lignes 1 à 6
- Pied de page : ligne 7, cellules 0 à 14 ; délai d'attente à la cellule 15

Utilisez `clearPage()` pour découper le contenu de la page loin de l'en-tête/pied de page.
</Step>

<Step title="Choisissez des polices lisibles">
| Zone | Police recommandée |
|---|---|
| En-tête/pied de page | `u8g2_font_spleen5x8_mu` |
| Contenu des pages | Choisissez pour la lisibilité ; ajuster l'espacement des lignes par les mesures de police |

<Note>
Tenez compte de l'ascension de la police et de la hauteur totale des lignes lors du calcul des décalages `y` entre les lignes.
</Note>
</Step>
</Steps>

## Considérations sur les performances

- Les mises à jour partielles ne redessinent que les régions que vous avez modifiées
- La mise en cache du texte évite les cycles de dessin/actualisation inutiles
- Le découpage continue de dessiner à l'intérieur de la région prévue et réduit le dépassement
- Les séquences protégées par mutex empêchent le déchirement du milieu d'image entre les tâches

## Dépannage

<AccordionGroup>
<Accordion title="Rien n'apparaît après l'initialisation">
- Confirmez que `initDisplay()` est appelé une fois
- Vérifiez l'adresse I2C (essayez `0x3C` et `0x3C << 1` selon le constructeur)
- Assurez-vous que SDA/SCL correspondent au `Pins.h` de votre carte.
</Accordion>

<Accordion title="Les mises à jour de l'affichage sont lentes ou scintillent">
- Utiliser les effacements/actualisations de région au lieu des effacements complets du tampon
- Regroupez votre dessin dans un bloc protégé par mutex
- Évitez les changements de police inutiles entre les appels de tirage
</Accordion>

<Accordion title="Le texte apparaît mal aligné verticalement">
- N'oubliez pas que U8G2 utilise une ligne de base pour `y`.
- Commencez la première ligne de police de 8 px à `y = 8` ou calculez à partir de la montée de la police.
</Accordion>

<Accordion title="Tâches bloquées ou bloquées">
- Libérez toujours le mutex dans les chemins d'erreur
- Préférez les wrappers de style RAII ou les modèles `goto cleanup`
</Accordion>
</AccordionGroup>
