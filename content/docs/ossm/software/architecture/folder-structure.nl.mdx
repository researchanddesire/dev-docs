# Mappenstructuur

De OSSM-firmware volgt een modulaire, op functies gebaseerde architectuur. Elke functie bevindt zich in een eigen naamruimtemap, waardoor de codebase gemakkelijker te navigeren en te onderhouden is.

<Info>
Blader door de broncode op GitHub: [Software/bron/](https://github.com/KinkyMakers/OSSM-hardware/tree/main/Software/src)
</Info>

## Ontwerpfilosofie

De firmware maakt gebruik van een **functiegebaseerde organisatie** waar gerelateerde code samenleeft:

- **Naamruimten over klassen** - Functies zijn georganiseerd als naamruimtefuncties in plaats van als klassenmethoden
- **Gezamenlijke bestanden** - De header, implementatie en gerelateerde code van elke functie bevinden zich in dezelfde map
- **Algemene statusstructuren** - Gedeelde status wordt beheerd via speciale statusstructuren in plaats van via klasseleden
- **Staatloze modules** - Functiefuncties werken op basis van de globale status, waardoor ze gemakkelijker te testen en te redeneren zijn

<Note>
De klasse `OSSM` in `ossm/OSSM.h` blijft behouden voor achterwaartse compatibiliteit met de verwerking van BLE-opdrachten. Nieuwe functies moeten gebruik maken van staatloze naamruimtefuncties.
</Note>

### Staatsmachine (`ossm/state/`)

De componenten van de staatsmachine zijn gescheiden voor duidelijkheid en testbaarheid.

| Bestand | Doel |
|------|---------|
| [`machine.h`](https://github.com/KinkyMakers/OSSM-hardware/blob/main/Software/src/ossm/state/machine.h) | Overgangstabeldefinitie met behulp van Boost.SML |
| [`actions.h`](https://github.com/KinkyMakers/OSSM-hardware/blob/main/Software/src/ossm/state/actions.h) / `actions.cpp` | Statusovergangsacties (display-updates, motorbesturing) |
| [`guards.h`](https://github.com/KinkyMakers/OSSM-hardware/blob/main/Software/src/ossm/state/guards.h) / `guards.cpp` | Voorwaardelijke controles op overgangen |
| `state.h` / `state.cpp` | Initialisatie van de staatsmachine en globale instantie |

**Staatsstructuren** beheren verschillende aspecten van de applicatie:

| Bestand | Doel |
|------|---------|
| `session.h` | Huidige sessie (starttijd, aantal slagen, afstand) |
| `settings.h` | Gebruikersinstellingen (snelheid, slag, gevoel, diepte, patroon) |
| `calibration.h` | Homing-status (sensoroffset, slagstappen, homed-status) |
| `motion.h` | Bewegingsdoelen (positie, snelheid, tijd) |
| `menu.h` | Huidige menuselectie |
| `ble.h` | Bluetooth-verbindingsstatus |
| `error.h` | Foutmeldingen |

<Tip>
Zie [Architectuur van staatsmachines](/ossm/software/architecture/state-machine) voor meer informatie over hoe de statusmachine werkt.
</Tip>

### UI-pagina's (`ossm/pages/`)

Elk scherm in de gebruikersinterface heeft zijn eigen module.

| Module | Beschrijving |
|--------|-------------|
| `hello.h` | Opstartscherm met geanimeerde logo's |
| `preflight.h` | Veiligheidscontrolescherm 'Verlaag snelheid om te starten' |
| `error.h` | Foutweergave met helpoptie |
| `update.h` | OTA-updateschermen (controleren, bijwerken, geen update) |
| `wifi.h` | WiFi-configuratieportaal |
| `help.h` | Hulp- en ondersteuningsinformatie |

### Bedrijfsmodi

Elke bedrijfsmodus is een op zichzelf staande module met zijn bewegingsbesturingslogica.

| Module | Beschrijving |
|--------|-------------|
| `simple_penetration/` | Basisbeweging heen en weer met gecontroleerde snelheid |
| `stroke_engine/` | Complexe patronen met behulp van de StrokeEngine-bibliotheek |

### Beheer gebruikersinterfaces

| Module | Beschrijving |
|--------|-------------|
| `menu/` | Navigatie en weergave in het hoofdmenu |
| `pattern_controls/` | Patroonselectie-interface voor de Stroke Engine-modus |
| `play_controls/` | Bediening voor snelheid, slag, diepte en sensatie |

### Functiemodules

| Module | Beschrijving |
|--------|-------------|
| `homing/` | Startvolgorde (voorwaartse scan, achterwaartse scan, kalibratie) |

## Bibliotheken

### Boost.SML (`include/boost/sml.hpp`)

[Boost.SML](https://boost-ext.github.io/sml/) is een statusmachinebibliotheek met alleen headers. Het is rechtstreeks in het project opgenomen voor versiestabiliteit.

### Slagmotor (`lib/StrokeEngine/`)

Een aangepaste versie van [theelims/StrokeEngine](https://github.com/theelims/StrokeEngine) die bewegingspatronen genereert. De bibliotheek wordt geleverd en aangepast aan OSSM-specifieke vereisten.

## Configuratie bouwen

Het `platformio.ini`-bestand definieert de build-omgevingen:

| Omgeving | Doel |
|-------------|---------|
| `development` | Lokale ontwikkeling met logboekregistratie voor foutopsporing |
| `staging` | Testen vóór de release |
| `production` | Release-builds met optimalisaties |
| `test` | Configuratie van eenheidstest |
