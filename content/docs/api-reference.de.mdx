# API-Referenz

Endpunktseiten in diesem Abschnitt werden aus dem aktuellen R+D Dashboard OpenAPI-Dokument generiert. Verwenden Sie die Navigation, um eine Ressource und eine Operation auszuwählen.

Bevor Sie einen Endpunkt aufrufen, lesen Sie [API-Konventionen](/dashboard/api/introduction) und konfigurieren Sie [Authentifizierung](/dashboard/api/authentication).

Die generierten Operationsseiten sind maßgeblich für Anfragepfade, Parameter,
Request-Bodies und Antworten.
