# API-Referenz

Endpunktseiten in diesem Abschnitt werden aus dem aktuellen Dashboard OpenAPI-Dokument generiert. Verwenden Sie die Navigation, um eine Ressource und einen Vorgang auszuwählen.

Bevor Sie einen Endpunkt aufrufen, lesen Sie [API-Konventionen](/dashboard/api/introduction) und konfigurieren Sie [Authentifizierung](/dashboard/api/authentication).

Generierte Operationsseiten sind kanonisch für Anforderungspfade, Parameter, Textkörper und Antworten.
