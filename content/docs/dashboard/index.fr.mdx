# API du tableau de bord

Commencez par les [conventions API](/dashboard/api/introduction), puis configurez [l'authentification](/dashboard/api/authentication). Les pages de point de terminaison sont générées à partir du document OpenAPI actuel sous [Référence API](/api-reference).

N'utilisez pas d'anciennes pages de point de terminaison manuscrites comme schémas ; la référence générée est canonique.

Pour obtenir de l'aide sur un compte, un couplage, un partenaire ou un abonnement, utilisez les [Guides de l'utilisateur](https://docs.researchanddesire.com/account-and-dashboard/account-password).
