# API du tableau de bord

Commencez par les [conventions de l’API](/dashboard/api/introduction), puis configurez [l’authentification](/dashboard/api/authentication). Les pages des points de terminaison sont générées à partir du document OpenAPI actuel dans la [Référence de l’API](/api-reference).

N’utilisez pas d’anciennes pages de points de terminaison rédigées manuellement comme schémas ; la référence générée fait autorité.

Pour obtenir de l’aide concernant un compte, le couplage, les partenariats ou les abonnements, consultez les [Guides de l’utilisateur](https://docs.researchanddesire.com/account-and-dashboard/account-password).
