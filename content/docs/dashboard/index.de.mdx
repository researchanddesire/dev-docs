# Dashboard-API

Beginnen Sie mit [API-Konventionen](/dashboard/api/introduction) und konfigurieren Sie dann [Authentifizierung](/dashboard/api/authentication). Endpunktseiten werden aus dem aktuellen OpenAPI-Dokument unter [API-Referenz](/api-reference) generiert.

Verwenden Sie keine alten handgeschriebenen Endpunktseiten als Schemata. Die generierte Referenz ist kanonisch.

Für Konto-, Kopplungs-, Partner- oder Abonnementhilfe verwenden Sie [Benutzerhandbücher](https://docs.researchanddesire.com/account-and-dashboard/account-password).
