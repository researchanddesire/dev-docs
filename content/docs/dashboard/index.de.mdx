# Dashboard-API

Beginnen Sie mit den [API-Konventionen](/dashboard/api/introduction) und konfigurieren Sie anschließend die [Authentifizierung](/dashboard/api/authentication). Die Endpunktseiten werden aus dem aktuellen OpenAPI-Dokument unter [API-Referenz](/api-reference) generiert.

Verwenden Sie keine alten, manuell erstellten Endpunktseiten als Schemata; die generierte Referenz ist maßgeblich.

Bei Fragen zu Konto, Kopplung, Partnerschaften oder Abonnements verwenden Sie die [Benutzerhandbücher](https://docs.researchanddesire.com/account-and-dashboard/account-password).
