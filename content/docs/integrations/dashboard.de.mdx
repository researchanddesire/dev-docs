# Dashboard-Integration

1. Lesen Sie die [API-Konventionen](/dashboard/api/introduction).
2. Konfigurieren Sie [Authentifizierung](/dashboard/api/authentication).
3. Verwenden Sie die generierte [API-Referenz](/api-reference) für aktuelle Pfade, Parameter, Request-Bodies und Antworten.
4. Behandeln Sie Autorisierungsfehler, Validierungsfehler, Wiederholungsversuche und nicht verfügbare Geräte ausdrücklich.

Die generierte OpenAPI-Referenz ist die Quelle für Endpunktschemata. Anweisungen zum Kundenkonto und zur Kopplung finden Sie in den [Benutzerhandbüchern](https://docs.researchanddesire.com/account-and-dashboard/devices-pairing).
