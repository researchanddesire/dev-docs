# Dashboard-Integration

1. Lesen Sie die [API-Konventionen](/dashboard/api/introduction).
2. Konfigurieren Sie [Authentifizierung](/dashboard/api/authentication).
3. Verwenden Sie den generierten [API-Referenz](/api-reference) für aktuelle Pfade, Parameter, Anforderungstexte und Antworten.
4. Behandeln Sie Autorisierungsfehler, Validierungsfehler, Wiederholungsversuche und nicht verfügbare Geräte explizit.

Die generierte OpenAPI-Referenz ist die Quelle für Endpunktschemata. Verbraucherkonto und Kopplungsanweisungen sind im [Benutzerhandbücher](https://docs.researchanddesire.com/account-and-dashboard/devices-pairing) verfügbar.
