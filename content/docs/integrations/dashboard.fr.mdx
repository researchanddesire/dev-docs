# Intégration du tableau de bord

1. Lisez les [conventions de l'API](/dashboard/api/introduction).
2. Configurez [l'authentification](/dashboard/api/authentication).
3. Utilisez la [Référence API](/api-reference) générée pour les chemins actuels, les paramètres, les corps de requête et les réponses.
4. Gérez explicitement les échecs d’autorisation, les erreurs de validation, les réessais et les appareils indisponibles.

La référence OpenAPI générée est la source des schémas de point de terminaison. Les instructions relatives au compte consommateur et au couplage sont disponibles dans les [Guides de l'utilisateur](https://docs.researchanddesire.com/account-and-dashboard/devices-pairing).
