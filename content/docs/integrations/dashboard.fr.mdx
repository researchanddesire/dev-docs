# Intégration du tableau de bord

1. Lisez les [Conventions API](/dashboard/api/introduction).
2. Configurez [l'authentification](/dashboard/api/authentication).
3. Utilisez la [Référence API](/api-reference) générée pour les chemins, paramètres, corps de requête et réponses actuels.
4. Gérez explicitement les échecs d’autorisation, les erreurs de validation, les tentatives et les appareils indisponibles.

La référence OpenAPI générée est la source des schémas de point de terminaison. Le compte consommateur et les instructions de couplage sont disponibles dans les [Guides de l'utilisateur](https://docs.researchanddesire.com/account-and-dashboard/devices-pairing) .
