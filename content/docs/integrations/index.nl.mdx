# Ondersteunde integratie-interfaces

| Doel | Interface |
| --- | --- |
| Cloud-geautoriseerde gegevens en acties | [Dashboard-API](/dashboard/api/introduction) |
| OSSM draadloze apparaatcommunicatie | [OSSM BLE](/ossm/software/communication/ble) |
| OSSM-hardwaresignalen | [OSSM GPIO](/ossm/software/communication/gpio) |
| Een RADR-apparaatdefinitie toevoegen of bijwerken | [RADR-apparaatregister](/radr/software/device-registry/introduction) |
| Een ondersteund DTT-accessoire uitlezen | [DTT-accessoirepoort](/dtt/specs/accessory-port) |

Een integratie moet het stopgedrag, de invoerlimieten en de ontkoppelde status van het apparaat behouden. Controleer de doelfirmware en hardwarerevisie voordat u op een veld of signaal vertrouwt.
