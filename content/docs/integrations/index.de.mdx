# Unterstützte Integrationsschnittstellen

| Ziel | Schnittstelle |
| --- | --- |
| Cloud-autorisierte Daten und Aktionen | [Dashboard-API](/dashboard/api/introduction) |
| Drahtlose OSSM-Gerätekommunikation | [OSSM BLE](/ossm/software/communication/ble) |
| OSSM-Hardwaresignale | [OSSM GPIO](/ossm/software/communication/gpio) |
| RADR-Gerätedefinition hinzufügen oder aktualisieren | [RADR-Geräteregistrierung](/radr/software/device-registry/introduction) |
| Unterstütztes DTT-Zubehör auslesen | [DTT-Zubehöranschluss](/dtt/specs/accessory-port) |

Eine Integration muss das Stoppverhalten, die Eingabegrenzen und den Zustand des
Geräts bei getrennter Verbindung beibehalten. Überprüfen Sie die Firmware und
die Hardware-Revision des Ziels, bevor Sie sich auf ein Feld oder Signal
verlassen.
