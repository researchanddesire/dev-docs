# Unterstützte Integrationsoberflächen

| Ziel | Schnittstelle |
| --- | --- |
| Cloud-autorisierte Daten und Aktionen | [Dashboard-API](/dashboard/api/introduction) |
| Drahtlose OSSM-Gerätekommunikation | [OSSM BLE](/ossm/software/communication/ble) |
| OSSM-Hardwaresignale | [OSSM GPIO](/ossm/software/communication/gpio) |
| Fügen Sie eine RADR-Gerätedefinition hinzu oder aktualisieren Sie sie | [RADR-Geräteregistrierung](/radr/software/device-registry/introduction) |
| Lesen Sie ein unterstütztes DTT-Zubehör | [DTT-Zubehöranschluss](/dtt/specs/accessory-port) |

Eine Integration muss das Stoppverhalten, die Eingabegrenzen und den getrennten Zustand des Geräts beibehalten. Überprüfen Sie die Firmware- und Hardwareversion des Ziels, bevor Sie sich auf ein Feld oder Signal verlassen.
