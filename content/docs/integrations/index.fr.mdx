# Surfaces d'intégration prises en charge

| But | Interface |
| --- | --- |
| Données et actions autorisées dans le cloud | [API du tableau de bord](/dashboard/api/introduction) |
| Communication des appareils sans fil OSSM | [OSSM BLE](/ossm/software/communication/ble) |
| Signaux matériels OSSM | [OSSM GPIO](/ossm/software/communication/gpio) |
| Ajouter ou mettre à jour une définition de périphérique RADR | [Registre des appareils RADR](/radr/software/device-registry/introduction) |
| Lire un accessoire TNT pris en charge | [Port accessoire TNT](/dtt/specs/accessory-port) |

Une intégration doit préserver le comportement d'arrêt de l'appareil, les limites d'entrée et l'état déconnecté. Vérifiez la révision du micrologiciel et du matériel cible avant de vous fier à un champ ou à un signal.
