# Interfaces d’intégration prises en charge

| But | Interface |
| --- | --- |
| Données et actions autorisées par le cloud | [API du Dashboard](/dashboard/api/introduction) |
| Communication des appareils sans fil OSSM | [OSSM BLE](/ossm/software/communication/ble) |
| Signaux matériels OSSM | [OSSM GPIO](/ossm/software/communication/gpio) |
| Ajouter ou mettre à jour une définition d'appareil RADR | [Registre des appareils RADR](/radr/software/device-registry/introduction) |
| Lire un accessoire DTT pris en charge | [Port accessoire DTT](/dtt/specs/accessory-port) |

Une intégration doit préserver le comportement d'arrêt de l'appareil, les
limites d'entrée et l'état déconnecté. Vérifiez le micrologiciel cible et la
révision du matériel cible avant de vous fier à un champ ou à un signal.
