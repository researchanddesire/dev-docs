# Dashboard integration

1. Read the [API conventions](/dashboard/api/introduction).
2. Configure [authentication](/dashboard/api/authentication).
3. Use the generated [API Reference](/api-reference) for current paths, parameters, request bodies, and responses.
4. Handle authorization failures, validation errors, retries, and unavailable devices explicitly.

The generated OpenAPI reference is the source for endpoint schemas. Consumer account and pairing instructions live in the [User Guides](https://docs.researchanddesire.com/account-and-dashboard/devices-pairing).
