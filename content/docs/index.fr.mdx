# Construire avec R+D

Intégrez les comptes R+D, les données de la plateforme et les actions prises en charge à votre produit. Demandez un accès développeur, enregistrez une application OAuth et connectez votre premier utilisateur.

Utilisez ces documents pour le Dashboard API, le micrologiciel de l'appareil, les protocoles pris en charge, les interfaces matérielles et les intégrations.
