# Référence API

Les pages de point de terminaison de cette section sont générées à partir du document Dashboard OpenAPI actuel. Utilisez la navigation pour choisir une ressource et une opération.

Avant d'appeler un point de terminaison, lisez les [Conventions API](/dashboard/api/introduction) et configurez [l'authentification](/dashboard/api/authentication).

Les pages d'opération générées sont canoniques pour les chemins de requête, les paramètres, les corps et les réponses.
