# Référence API

Les pages des points de terminaison de cette section sont générées à partir du
document OpenAPI actuel de R+D Dashboard. Utilisez la navigation pour choisir
une ressource et une opération.

Avant d'appeler un point de terminaison, consultez les [conventions de l'API](/dashboard/api/introduction)
et configurez [l'authentification](/dashboard/api/authentication).

Les pages d'opérations générées font autorité pour les chemins de requête, les
paramètres, les corps de requête et les réponses.
