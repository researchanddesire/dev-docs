# Choose an interface

- Use the [Dashboard API](/dashboard/api/introduction) for account-authorized cloud data and actions.
- Use the [OSSM BLE protocol](/ossm/software/communication/ble) or [GPIO interface](/ossm/software/communication/gpio) for supported device-level integrations.
- Use the [RADR device registry](/radr/software/device-registry/introduction) when adding supported RADR device behavior.
- Use the [DTT accessory port](/dtt/specs/accessory-port) only within its documented electrical and sensor limits.

# Before implementation

1. Read the authentication and safety constraints for the chosen interface.
2. Confirm the target firmware and hardware revision.
3. Test loss of connectivity, invalid input, and stop behavior.
4. Use the generated [API Reference](/api-reference) for endpoint schemas instead of copying examples from old guides.

Physical assembly belongs in [R+D Assembly](https://ohai.researchanddesire.com/ossm); consumer pairing and operation belong in the [User Guides](https://docs.researchanddesire.com/).
