# API-referentie

De eindpuntpagina's in deze sectie worden gegenereerd op basis van het huidige
OpenAPI-document van R+D Dashboard. Gebruik de navigatie om een resource en een
bewerking te kiezen.

Lees voordat u een eindpunt aanroept de [API-conventies](/dashboard/api/introduction)
en configureer [authenticatie](/dashboard/api/authentication).

De gegenereerde operatiepagina's zijn leidend voor aanvraagpaden, parameters,
request-bodies en antwoorden.
