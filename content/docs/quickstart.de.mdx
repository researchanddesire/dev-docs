## Ihr Produkt mit R+D verbinden

1. [Möglichkeiten Ihrer App entdecken](/de/build-an-app).
2. [Entwicklerkonto beantragen](/de/build-an-app/getting-started).
3. [Erste Anwendung erstellen](/de/build-an-app/first-application) und Tester einladen.
4. [Verbindungsbeispiel ausführen](/de/build-an-app/examples), mit TypeScript, JavaScript oder Python.

Für Skripte nur für Ihr eigenes Konto verwenden Sie [persönliche API-Token](/de/dashboard/api/authentication). Für Firmware und Hardware wählen Sie unten eine Schnittstelle.

# Wählen Sie eine Schnittstelle

- Verwenden Sie die [Dashboard API](/dashboard/api/introduction) für kontoautorisierte Cloud-Daten und -Aktionen.
- Verwenden Sie das [OSSM BLE protocol](/ossm/software/communication/ble) oder die [GPIO interface](/ossm/software/communication/gpio) für unterstützte Integrationen auf Geräteebene.
- Verwenden Sie die [RADR device registry](/radr/software/device-registry/introduction), wenn Sie unterstütztes RADR-Geräteverhalten hinzufügen.
- Verwenden Sie den [DTT accessory port](/dtt/specs/accessory-port) nur innerhalb der dokumentierten elektrischen und Sensorgrenzen.

# Vor der Umsetzung

1. Lesen Sie die Authentifizierungs- und Sicherheitsbeschränkungen für die ausgewählte Schnittstelle.
2. Bestätigen Sie die Ziel-Firmware und die Hardware-Revision.
3. Testen Sie Verbindungsverlust, ungültige Eingaben und Stoppverhalten.
4. Verwenden Sie die generierte [API Reference](/api-reference) für Endpunktschemata, anstatt Beispiele aus alten Handbüchern zu kopieren.

Die physische Montage gehört in [R+D Assembly](https://ohai.researchanddesire.com/ossm); die Kopplung und Bedienung durch Verbraucher gehören in die [User Guides](https://docs.researchanddesire.com/).
