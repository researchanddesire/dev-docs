# Wählen Sie eine Schnittstelle

- Verwenden Sie [Dashboard-API](/dashboard/api/introduction) für kontoautorisierte Cloud-Daten und -Aktionen.
- Verwenden Sie [OSSM BLE-Protokoll](/ossm/software/communication/ble) oder [GPIO-Schnittstelle](/ossm/software/communication/gpio) für unterstützte Integrationen auf Geräteebene.
- Verwenden Sie [RADR-Geräteregistrierung](/radr/software/device-registry/introduction), wenn Sie das unterstützte RADR-Geräteverhalten hinzufügen.
- Verwenden Sie den [DTT-Zubehöranschluss](/dtt/specs/accessory-port) nur innerhalb der dokumentierten elektrischen und Sensorgrenzen.

# Vor der Umsetzung

1. Lesen Sie die Authentifizierungs- und Sicherheitsbeschränkungen für die ausgewählte Schnittstelle.
2. Bestätigen Sie die Ziel-Firmware- und Hardware-Revision.
3. Testen Sie Verbindungsverlust, ungültige Eingaben und Stoppverhalten.
4. Verwenden Sie das generierte [API-Referenz](/api-reference) für Endpunktschemata, anstatt Beispiele aus alten Handbüchern zu kopieren.

Physische Montage gehört in [R+D-Montage](https://ohai.researchanddesire.com/ossm); Die Verbraucherkopplung und -bedienung gehören zum [Benutzerhandbücher](https://docs.researchanddesire.com/).
