Cette section couvre le micrologiciel RADR, y compris l'architecture, la configuration du développement et la manière de modifier ou de contribuer à la base de code.

## Présentation du micrologiciel

RADR fonctionne sur un microcontrôleur ESP32-S3 avec un micrologiciel personnalisé écrit en C++ à l'aide du framework Arduino et de PlatformIO.

| Composant | Technologie |
|-----------|------------|
| MCU | ESP32-S3 avec PSRAM |
| Cadre | Arduino pour ESP32 |
| Construire un système | PlateformeIO |
| Langue | C++ |
| Afficher la bibliothèque | TFT_eSPI |
| Pile BLE | Agile |

## Présentation de l'architecture

### Principaux composants

| Composant | But |
|-----------|---------|
| Machine à états | Gère les états de l'écran et le flux de navigation |
| Gestionnaire de périphériques | Gère la découverte et la connexion des appareils Bluetooth |
| Pilote d'affichage | Rend l'interface utilisateur à l'aide de TFT_eSPI avec mise en mémoire tampon du canevas |
| Gestionnaire d'entrée | Traite les entrées de l'encodeur, des boutons et du pare-chocs |
| Système de rétroaction | Contrôle les LED, le buzzer et les vibrations |
| Registre des appareils | Mappe les UUID Bluetooth aux types d’appareils |

### Services clés

```
├── BluetoothService    # BLE scanning and connection
├── DisplayService      # Screen rendering
├── InputService        # Encoder and button handling
├── FeedbackService     # LED, buzzer, vibration
├── DeviceService       # Connected device control
├── WiFiService         # WiFi and OTA updates
└── StorageService      # LittleFS configuration
```

## Environnement de développement

### Conditions préalables

- [Code Visual Studio](https://code.visualstudio.com/)
- [Extension PlateformeIO](https://platformio.org/install/ide?install=vscode)
- Câble USB-C pour flasher

### Commencer

<Steps>
<Step title="Cloner le référentiel">
```bash
git clone https://github.com/researchanddesire/radr-wireless-remote.git
cd radr-wireless-remote/Software
```
</Step>

<Step title="Ouvrir dans VS Code">
Ouvrez le dossier `Software` dans VS Code. PlatformIO détectera automatiquement la configuration du projet.
</Step>

<Step title="Construire le firmware">
Cliquez sur le bouton PlatformIO Build ou exécutez :
```bash
pio run
```
</Step>

<Step title="Flasher sur l'appareil">
Connectez RADR via USB-C et cliquez sur Télécharger, ou exécutez :
```bash
pio run --target upload
```
</Step>
</Steps>

## Principales fonctionnalités

### Rendu basé sur un canevas

RADR utilise un rendu de canevas à double tampon pour des mises à jour d'affichage fluides :

- Les sprites plein écran empêchent le scintillement
- Mises à jour partielles pour les zones critiques en termes de performances
- Taux de rafraîchissement constant de l'interface utilisateur de 60 ips

### Architecture des machines à états

L'interface utilisateur utilise une machine à états hiérarchique :

- Transitions claires entre les écrans
- Logique d'état isolé pour chaque écran
- Gestion des entrées pilotées par les événements

### Registre des appareils

RADR prend en charge plusieurs types d'appareils via un registre à deux niveaux :

| Enregistrement | Description |
|----------|-------------|
| Intégré | Prise en charge des appareils R+D codés en dur (OSSM) |
| Dynamique | Définitions de périphériques Buttplug.io basées sur JSON |

Le registre dynamique (`registry.json`) peut être mis à jour via des mises à jour du micrologiciel pour ajouter la prise en charge de nouveaux appareils sans modification du code.

## Fichiers de configuration

| Déposer | But |
|------|---------|
| `platformio.ini` | Construire la configuration et les dépendances |
| `src/config.h` | Définitions et constantes des broches matérielles |
| `data/registry.json` | Mappages UUID du périphérique Buttplug.io |

## Contribuer

Lisez les [directives de contribution](https://github.com/researchanddesire/radr-wireless-remote/blob/main/CONTRIBUTING.md) avant de soumettre une modification concernant la branche `main`.
