Cette section couvre la conception du PCB principal RADR, y compris les schémas, les spécifications des composants et les fichiers de fabrication.

## Aperçu de la carte

| Spécification | Valeur |
|---------------|-------|
| Nom de la carte | OSSM Wireless |
| Version | v0.4 |
| Microcontrôleur | ESP32-S3 avec PSRAM |
| Logiciel de conception | Altium Designer |
| Nombre de couches | 2 (estimé) |

Le PCB RADR intègre toute l'électronique requise pour une télécommande sans fil autonome, y compris le microcontrôleur, l'interface d'affichage, la gestion de l'alimentation, les entrées utilisateur et les systèmes de rétroaction.

## Composants de base

### Microcontrôleur

| Paramètre | Valeur |
|-----------|-------|
| MCU | ESP32-S3 |
| Mémoire | Comprend de la PSRAM |
| Sans fil | WiFi + Bluetooth LE |
| Tension de fonctionnement | 3.3V |

L'ESP32-S3 fournit :
- Processeur Xtensa LX7 double cœur
- Bluetooth Low Energy intégré pour la communication des appareils
- Suffisamment de GPIO pour toutes les entrées, sorties et périphériques
- Modes de veille à faible consommation pour économiser la batterie

### Gestion de l'alimentation

| Composant | Fonction |
|-----------|----------|
| Connecteur USB-C | Entrée de charge 5V |
| CI de charge | Chargement de la batterie LiPo |
| MAX17048 | Jauge de batterie (surveillance de la batterie) |
| LDO/Régulateur | Alimentation du système 3.3V |

Le système électrique prend en charge :
- Chargement USB-C (entrée 5V)
- Indicateur LED de chargement du matériel
- Pourcentage de batterie précis via une jauge de batterie I²C
- Courant en veille profonde < 100μA

### Interface d'affichage

| Paramètre | Valeur |
|-----------|-------|
| Type d'affichage | TFT LCD |
| Résolution | 320 x 240 pixels |
| Profondeur de couleur | 16-bit (RGB565) |
| Interface | SPI |
| Rétroéclairage | Contrôlé par PWM |

### Entrées utilisateur

| Entrée | Type | GPIO |
|-------|------|------|
| Encodeur gauche | Rotatif + bouton-poussoir | GPIO 10, 11 |
| Encodeur droit | Rotatif + bouton-poussoir | GPIO 42, 41 |
| Épaule gauche | Bouton-poussoir | GPIO 48 |
| Épaule droite | Bouton-poussoir | GPIO 1 |
| Sous l'écran gauche | Bouton-poussoir | GPIO 38 |
| Centre sous l'écran | Bouton-poussoir | GPIO 39 |
| Sous l'écran à droite | Bouton-poussoir | GPIO 40 |

<Note>
Les affectations GPIO indiquées concernent les cartes v0.4 avec PSRAM. Les cartes v1.x antérieures utilisent des broches différentes pour l'encodeur gauche (GPIO 35, 36) et les LED (GPIO 37).
</Note>

### Sorties de rétroaction

| Composant | Type | GPIO |
|-----------|------|------|
| LED d'état | WS2812B RGB (x3) | GPIO 12 |
| Ronfleur | Piézoélectrique | GPIO 2 |
| Moteur vibrant | Moteur ERM | GPIO 47 |

### Extension

| Connecteur | Interface | Objectif |
|-----------|-----------|---------|
| QWIIC | I²C | Capteurs/périphériques externes |
| USB-C | USB 2.0 | Programmation et recharge |

## Sections schématiques

Le schéma est organisé en blocs fonctionnels :

| Section | Description |
|---------|-------------|
| Alimentation | Entrée USB-C, circuit de charge, régulation de tension |
| MCU | ESP32-S3, quartz, réinitialisation, sélection de démarrage |
| Affichage | Connecteur TFT LCD, pilote de rétroéclairage |
| Entrées | Encodeurs rotatifs, boutons, résistances pull-up/pull-down |
| Rétroaction | Ligne de données LED, pilote de buzzer, pilote de moteur |
| Batterie | Jauge de batterie MAX17048, connecteur de batterie |
| Extension | Connecteur QWIIC, connecteur de programmation |

## Considérations relatives à la disposition du PCB

### Placement des composants

- **MCU** positionné au centre pour un routage équilibré des pistes
- Connecteur **USB-C** sur le bord de la carte pour plus d'accessibilité
- Connecteur d'affichage orienté pour l'acheminement du câble plat vers le boîtier
- Connecteur de batterie positionné pour le placement interne de la batterie
- Connecteur **QWIIC** accessible pour les modules d'extension

### Considérations sur l'antenne

L'ESP32-S3 utilise une antenne PCB intégrée ou une antenne externe (selon la version). La zone de l’antenne doit être dégagée :
- Plans de masse directement en dessous
- Proximité de l'enceinte métallique
- Signaux de commutation haute fréquence

<Warning>
Ne placez pas de composants ni de pistes dans la zone d'exclusion de l'antenne. Cela dégrade considérablement les performances WiFi.
</Warning>

## Fabrication

### Fabrication de PCB

Spécifications recommandées pour la commande :

| Paramètre | Valeur |
|-----------|-------|
| Couches | 2 |
| Épaisseur | 1.6mm |
| Finition de surface | HASL ou ENIG |
| Poids du cuivre | 1oz |
| Masque de soudure | N'importe quelle couleur |
| Sérigraphie | Blanc |

### Options d'assemblage

| Méthode | Recommandé pour |
|--------|-----------------|
| Assemblage manuel | Prototypes, unités individuelles |
| Service PCBA | Quantités de production |

<Tip>
Des services tels que JLCPCB et PCBWay proposent une fabrication et un assemblage combinés de PCB. Téléchargez les Gerbers et la nomenclature pour une solution clé en main.
</Tip>

### Composants critiques

Ces composants nécessitent une attention particulière lors du montage :

| Composant | Remarques |
|-----------|-------|
| Module ESP32-S3 | Vérifiez l'orientation, assurez-vous que tous les plots sont soudés |
| Connecteur USB-C | Nécessite un alignement précis, vérifiez les courts-circuits |
| MAX17048 | Petit boîtier QFN, nécessite une refusion appropriée |
| LED WS2812B | Sensibles à la chaleur, respectez le profil de refusion |

## Dépannage

<AccordionGroup>
<Accordion title="La carte ne s'allume pas">
- Vérifiez la connexion et le câble USB-C
- Vérifiez la sortie du régulateur 3.3V
- Vérifiez les courts-circuits sur les rails d'alimentation
- Assurez-vous que la batterie est connectée et chargée
</Accordion>

<Accordion title="L'affichage ne fonctionne pas">
- Vérifiez la connexion du câble ruban
- Vérifiez les signaux SPI avec un oscilloscope
- Confirmez le signal PWM du rétroéclairage
- Testez les rails d'alimentation de l'écran
</Accordion>

<Accordion title="Bluetooth ne se connecte pas">
- Vérifiez la zone de l'antenne pour les courts-circuits ou les ponts
- Vérifiez que l'ESP32-S3 est correctement programmé
- Assurez-vous qu'il n'y a pas de métal à proximité de la zone de l'antenne
- Testez avec le blindage RF retiré (le cas échéant)
</Accordion>

<Accordion title="La batterie ne charge pas">
- Vérifiez que les résistances USB-C CC sont présentes
- Vérifiez les connexions du circuit intégré de charge
- Mesurez la tension de la batterie au niveau du connecteur
- Confirmez le circuit LED de charge
</Accordion>

<Accordion title="Les boutons ne répondent pas">
- Vérifiez les résistances pull-up/pull-down
- Vérifiez les affectations GPIO dans le firmware
- Testez la continuité entre le bouton et le MCU
- Vérifiez l'absence de soudures froides
</Accordion>
</AccordionGroup>
