RADR fournit un retour visuel, audio et haptique pour communiquer l'état de l'appareil sans que vous ayez à regarder l'écran.

## Système LED

RADR dispose de trois LED RVB (WS2812B) positionnées autour de l'appareil :

| Position | Emplacement | Objectif principal |
|----------|----------|-----------------|
| LED 0 | Encodeur gauche | Indicateur de mode vitesse |
| LED 1 | Milieu | État de connexion/lecture |
| DEL 2 | Encodeur droit | Indicateur de mode actif |

### Couleurs et significations des LED

#### États du système

| État | DIRIGÉ | Couleur | Valeur HSV | Luminosité |
|-------|-----|-------|-----------|------------|
| Recherche/numérisation | Tous | Bleu | 150 | 255 (pulsé) |
| Inactif (Menu principal) | Tous | Blanc doux | 180 | 50 |
| Appareil connecté | Milieu | Blanc | — | 50 |
| En pause/arrêté | Milieu | Rouge | — | 255 |

#### Modes de contrôle OSSM

Lors du contrôle d'un OSSM, les LED de l'encodeur indiquent le mode actif :

| Mode | DIRIGÉ | Couleur | Description |
|------|-----|-------|-------------|
| Vitesse | Gauche | Violet | Toujours actif (la vitesse est toujours contrôlée par l'encodeur gauche) |
| Profondeur | Droite | Corail/Rouge | L'encodeur droit ajuste la profondeur |
| Sensation | Droite | Bleu | L'encodeur droit ajuste la sensation |
| Accident vasculaire cérébral | Droite | Vert | L'encodeur droit ajuste la course |

### Modèles de comportement des LED

| Modèle | Signification |
|---------|---------|
| Solide | État statique (connecté, en pause, etc.) |
| Pulsation | Analyse active ou recherche |
| Flash rapide | Commentaires en cas de pression sur un bouton ou de changement de mode |

## Modèles de sonnerie

RADR utilise un buzzer piézoélectrique (GPIO 2) pour fournir un retour audio pour les événements clés.

### Son de démarrage

**Modèle :** Séquence ascendante de 4 notes

| Note | Fréquence | Durée |
|------|-----------|----------|
| 1 | 523 Hz (C5) | 100 ms |
| 2 | 659 Hz (E5) | 100 ms |
| 3 | 784 Hz (G5) | 100 ms |
| 4 | 1047 Hz (C6) | 150 ms |

Joué lorsque RADR s'allume.

### Son d'arrêt

**Modèle :** Séquence décroissante de 4 notes

| Note | Fréquence | Durée |
|------|-----------|----------|
| 1 | 1047 Hz (C6) | 100 ms |
| 2 | 784 Hz (G5) | 100 ms |
| 3 | 659 Hz (E5) | 100 ms |
| 4 | 523 Hz (C5) | 150 ms |

Joué lors du passage en mode veille.

### Appareil connecté

**Modèle :** Séquence ascendante de 3 notes

| Note | Fréquence | Durée |
|------|-----------|----------|
| 1 | 1047 Hz (C6) | 80 ms |
| 2 | 1319 Hz (E6) | 80 ms |
| 3 | 1568 Hz (G6) | 120 ms |

Joué lors de la connexion réussie à un appareil.

### Appareil déconnecté

**Modèle :** Séquence décroissante de 3 notes

| Note | Fréquence | Durée |
|------|-----------|----------|
| 1 | 1568 Hz (G6) | 80 ms |
| 2 | 1319 Hz (E6) | 80 ms |
| 3 | 1047 Hz (C6) | 120 ms |

Joué lorsqu'un appareil se déconnecte.

### En pause

**Modèle :** Double bip

| Note | Fréquence | Durée |
|------|-----------|----------|
| 1 | 800 Hz | 150 ms |
| Écart | — | 100 ms |
| 2 | 800 Hz | 150 ms |

Joué lors d'une pause de lecture.

### Lecture/Reprise

**Motif :** Ascendant bicolore

| Note | Fréquence | Durée |
|------|-----------|----------|
| 1 | 1200 Hz | 100 ms |
| 2 | 1400 Hz | 100 ms |

Joué lors de la reprise de la lecture.

### Pièce Mario (œuf de Pâques)

**Modèle :** Son de pièce classique

| Note | Fréquence | Durée |
|------|-----------|----------|
| 1 | 2637 Hz (E7) | 80 ms |
| 2 | 3136 Hz (G7) | 300 ms |

Commentaires spéciaux pour certaines interactions.

## Retour de vibrations

RADR comprend un moteur de vibration (GPIO 47) pour le retour haptique. Les modèles de vibrations reflètent généralement les modèles de buzzer, fournissant un retour tactile qui fonctionne sans son.

### Cas d'utilisation des vibrations

| Événement | Vibration |
|-------|-----------|
| Appuyez sur le bouton | Pouls court |
| Changement de mode | Vibration rapide |
| Connexion | Double vibration |
| Pause/Arrêter | Forte vibration |

### Horaires des modèles de vibrations

| Modèle | Description | Durées d'impulsion (ms) |
|---------|-------------|---------------------|
| Impulsion unique | Commentaires rapides | 50 |
| Double impulsion | Commentaires de confirmation | 50, pause 200, 50 |
| Triple impulsion | Forte confirmation | 10, pause 50, 20, pause 50, 30 |
| Impulsion d'erreur | Indication d'erreur longue | 500 |
| Fermer | Impulsions descendantes | 150, 100, 100, 100 |
| Appareil connecté | Impulsions ascendantes | 100, 100, 150 |
| Appareil déconnecté | Impulsions descendantes | 150, 100, 100 |
| En pause | Double impulsion | 150, 150 |
| Lecture/Reprise | Double impulsion rapide | 100, 100 |

<Info>
Le retour de vibration vous aide à utiliser RADR au toucher, particulièrement utile dans des conditions de faible luminosité ou lorsque l'appareil est hors de vue directe.
</Info>

## Schéma de couleurs de l'interface utilisateur

L'écran du RADR utilise une palette de couleurs cohérente :

### Couleurs d'arrière-plan

| Élément | Code couleur | Description |
|---------|------------|-------------|
| Arrière-plan | 0x10c5 | Gris foncé (Gris 900) |
| Fond de texte | Blanc | Couleur du texte principal |
| Texte secondaire | 0xDEFB | Gris clair |
| Désactivé | 0x1082 | Gris très foncé |

### Couleurs du mode OSSM

| Mode | Code couleur | Nom de la couleur |
|------|------------|------------|
| Vitesse | 0x5013 | Violet Royal |
| Profondeur | 0xE186 | Corail chaud |
| Sensation | 0x3C9F | Bleu océan |
| Accident vasculaire cérébral | 0x4E8A | Vert forêt |

### Couleurs d'état

| État | Couleur |
|-------|-------|
| Actif/Normal | Blanc |
| En pause/arrêté | Rouge |
| Désactivé | Gris foncé |
| Sélectionné/mis en surbrillance | Couleurs d'accentuation |

## Calendrier des commentaires

| Événement | Temps de réponse |
|-------|---------------|
| Appuyez sur le bouton | < 10 ms |
| Changement d'encodeur | < 10 ms |
| Changement de mode | < 50 ms |
| Changement de couleur des LED | < 20 ms |

## Conseils pour utiliser les commentaires

<Tip>
Apprenez les sons du buzzer pour faire fonctionner RADR sans regarder. Le son connecté (ascendant) par rapport au son déconnecté (descendant) indique clairement l'état.
</Tip>

<Tip>
La LED de gauche (violet pour la vitesse) et la LED de droite (couleur du mode) vous indiquent en un coup d'œil quel paramètre chaque encodeur contrôle.
</Tip>

<Tip>
La LED rouge du milieu signifie toujours en pause ou arrêté. Le blanc signifie actif et prêt.
</Tip>
